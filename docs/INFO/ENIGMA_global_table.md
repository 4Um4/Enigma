## Методика
- `Files/+/-/Net`: `git diff --numstat <prev_milestone> <current_milestone>`.
- `Semantic Impact`: weighted score (runtime + causal + governance + tests + log(change_total)).
- `Arch Shift`: score смены архитектуры через каузальный/управленческий след и ширину новых артефактов.
- `Entropy Δ (norm)`: нормализованная `tanh`-оценка структурного дрейфа/консолидации в диапазоне `[-100, +100]`.
- `Stabilization Pressure`: давление стабилизации (tests + governance + docs) относительно объёма runtime-мутаций.
- `Quality Index`: `0.30*Semantic + 0.35*ArchShift + 0.35*Stabilization`.
- `Sustainable Velocity/h`: `Quality Index / Δhours` между соседними вехами.
- `Lineage=detached`: веха не входит в ancestry текущего `HEAD`.
