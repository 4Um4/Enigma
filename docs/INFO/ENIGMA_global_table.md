## Легенда метрик

| Метрика | Формула / Пояснение |
|:---|:---|
| **Churn** | (added + removed) / net — интенсивность изменений |
| **Арх. эффективность** | runtime функций на 1000 изменённых строк (added+removed) |
| **Ценность на 1000стр** | субъективная оценка ценности (1–10) / |чистый прирост| × 1000 |
| **Рефактор интенсивность** | removed / (added+removed) — доля удаления в работе |
| **Scope breadth** | new_files / files — доля новых файлов в вечере |
| **Арх. глубина** | runtime функций / new_files — плотность новой логики в новых файлах |
| **Доля тестов** | tests / (runtime + tests) |
