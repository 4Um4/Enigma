### I. ПАТЧ АРХИТЕКТУРЫ: 4 СЛОЯ ВОСПРИЯТИЯ

Эти слои не заменяют физику (L0, L1, L2). Они являются **компрессорами**, транслирующими физику в реактивный интерфейс.

#### 1. Stigmergy Layer (Следы среды) — L0
**Проблема:** Градиенты (`AUTHORITY_INSTABILITY = 0.8`) невидимы.  
**Решение:** Мир оставляет физические следы, которые NPC и игрок считывают напрямую.

*   **Сущность `WorldTrace`:** Визуально-семантический слой поверх `SocialTraceField` из ADR-060.
    *   `type`: `BLOOD`, `BROKEN_GLASS`, `FEAR_SMELL`, `BURNED_FIREPLACE`, `ABANDONED_MEAL`.
    *   `intensity`, `decay_rate`, `source_entity`.
    *   `spatial_cell_id`: Привязка к ячейке `DynamicAffordanceField`.
*   **Интеграция с L0:** Когда `CombatSubscriber` генерирует травму, L0 генерирует `StateDeltas(domain=SPATIAL_TRACE, payload=TracePayload(safety_confidence=-0.3, taboo_strength=+0.2))`, а `TraceRenderer` на фронтенде парсит этот `TracePayload` и рисует `WorldTrace(type=BLOOD)` в `spatial_cell_id`.
*   **Интеграция с L1:** `PerceptualKernel` сканирует следы. NPC не знает "здесь была драка" (абстракция), он видит `BLOOD(intensity=0.7)` и его `threat_gradient` скачет. Для игрока — это красная лужа на полу таверны.
*   **Код:** Добавить `traces: List[WorldTrace]` в `ClusterPressureField`.

#### 2. Social Memory Layer (Эпизоды) — L1
**Проблема:** `trust = 0.3` не вызывает эмоций.  
**Решение:** Память агента хранит не числа, а **эпизоды** — моменты нарушения или подтверждения ожиданий.

*   **Сущность `Episode`:**
    *   `actor`, `action` (`SAVED_ME`, `HURT_ME`, `LIED`, `IGNORED`, `PROTECTED`).
    *   `context`: Где, когда, при ком.
    *   `affective_charge`: Насколько сильно запомнилось.
*   **Интеграция с L1:** Когда игрок бьет NPC, `MemorySystem` добавляет `Episode(HURT_ME, charge=0.9)`. Из эпизодов *выводится* `trust_delta` (число), но текст и поведение строятся из *эпизода*.
*   **Результат:** NPC говорит не "Я тебе не доверяю" (число), а "Ты тогда ударил меня, помнишь?" (эпизод).

#### 3. Identity Drift Layer (Дрейф Архетипов) — L1
**Проблема:** Плавное изменение `aggression` с 0.4 на 0.6 незаметно.  
**Решение:** Личность проходит через фазовые переходы — смену Архетипа.

*   **Сущность `ArchetypeLabel`:** Тег текущего состояния идентичности.
    *   `COWARD` -> `CAUTIOUS` -> `NEUTRAL` -> `PROTECTIVE` -> `LEADER` (социальная ось).
    *   `VICTIM` -> `SURVIVOR` -> `AVENGER` (ось насилия).
*   **Интеграция с L1:** `IdentityCore` по-прежнему хранит float-значения. Но когда `fear` падает ниже 0.3, а `social` растет, `ArchetypeLabel` меняется с `COWARD` на `CAUTIOUS`.
*   **Суть:** Смена Архетипа — это событие для SNIO (меняется стиль речи, словарь, микро-выражения). Игрок *заметит*, когда трусливая служанка начнет говорить твердым голосом.

#### 4. Micro-expression Layer (Приборная панель) — L2 -> Presentation
**Проблема:** Самая сложная симуляция мертва, если игрок видит только текст.  
**Решение:** Компилятор состояния в 5-8 видимых сигналов.

*   **Сущность `MicroExpressionProfile`:**
    *   `gaze_target`: На кого смотрит (или избегает смотреть).
    *   `gaze_duration`: Как долго держит контакт (0.1с — страх, 3с — вызов).
    *   `proximity_shift`: Движение к/от игрока (+0.5м, -1.0м).
    *   `speech_pacing`: Паузы между словами (0.1с — уверенность, 1.5с — страх/ложь).
    *   `gesture_tension`: Сжатые кулаки, скрещенные руки, дрожь.
*   **Интеграция с L1/L2:** `PresentationCompiler` (новый компонент L2) вызывается после `DecisionHub`.
    *   На вход: `DriveSystem`, `Episode`, `ArchetypeLabel`, `BodySchema`, `AffordanceVector` (из ADR-060).
    *   На выход: `PresentationContextDTO`, содержащий:
        1. `MicroExpressionProfile` (для UI: gaze, proximity).
        2. `KinematicProfile` (для UI: posture, velocity — заменяет старый MovementIntent).
        3. `BehaviorCorridor` (для SNIO: Soft/Hard ограничения генерации).
        4. `LLMStateInjection` (собранный промпт-каркас для Fast/Medium/Deep пути).
    *   *Вход:* `Drive(safety=0.2, social=0.8)`, `Episode(HURT_ME)`, `Archetype(SURVIVOR)`.
    *   *Выход:* `MicroExpression(gaze=AVOID, proximity=-0.5m, pacing=SLOW)`.
*   **SNIO получает это как системный промпт:** `[ROLE: SURVIVOR] [TRAUMA: PLAYER_HURT] [BEHAVIOR: AVOID_EYE_CONTACT, SLOW_SPEECH]`. И LLM *обречена* сгенерить тот самый дрожащий шепот, даже если она 4B.

# ТЗ: ENIGMA v2 — ЗАМКНУТАЯ АРХИТЕКТУРА (The Closed Loop)

**Онтология:** Мир = Поле. Личность = Агент. Взаимодействие = Деформация. Наблюдатель = Иммунитет.
**Запрет:** В системе не существует глобальной памяти, графа событий или объективной истории. Есть только давление среды и инерция агентов.

---

## I. ТРИ ФИЗИЧЕСКИХ УРОВНЯ (Границы ответственности)

### L0: WORLD FIELD (Среда без памяти)
Единственная объективная реальность. Не хранит "что произошло", хранит только "где сейчас болит".
*   **Содержимое:**
    *   `ClusterPressureField`: Социальные градиенты (Вакуум Власти, Вендетта, Дефицит).
    *   `AffordanceField`: Пространственные возможности (укрытие, угроза, проход).
*   **Правило:** Decay для градиентов = 0 (или аналитический). Давление не рассасывается само по себе, оно трансмутирует или поглощается действием.

### L1: AGENT STATE (Личность с инерцией)
Локальный, изолированный узел восприятия и воли. Не имеет доступа к истине. Имеет доступ только к искаженной проекции L0.
*   **Содержимое:**
    *   `IdentityCore`: Неизменяемые черты (агрессия, базовое доверие).
    *   `DriveSystem`: Конфликтующие потребности (выживание vs социум vs автономия).
    *   `MemorySystem`: Локальный вектор отношений (только с игроком и ключевыми NPC). Субъективна, искажена, инерционна.
    *   `PerceptualKernel`: Фильтр искажения поля L0.
*   **Правило:** Агент никогда не читает L0 напрямую. Только через `PerceptualKernel.project(field)`.

### L2: INTERACTION LAYER (Деформация)
Единственная точка контакта между L0 и L1. Цикл: `Восприятие → Решение → Действие → Деформация Поля`.

---

## II. ИНТЕГРАЦИЯ СУЩЕСТВУЮЩИХ СИСТЕМ (Трансформация v1 → v2)

| Сущность v1 | Статус в v2 | Уровень | Причина |
| :--- | :--- | :--- | :--- |
| `EventBus` / `EventDTO` | **Удалить** | - | Нарушает локальность. Заменен на прямую мутацию поля. |
| `CFRM / FieldDisturbance`| **Трансформировать** | L0 → L0 | Возмущение становится `Action.deformation`. |
| `PerceptualKernel` | **Остается** | L1 | Фильтр проекции L0 на L1. |
| `DecisionHub` | **Остается** | L1 | Разрешает конфликт драйвов L1 на основе проекции L0. |
| `AffectiveImprints` | **Остается** | L1 | Ядро инерции памяти агента. |
| `MacroGradient` (NPL) | **Остается** | L0 | Ось давления `ClusterPressureField`. |
| `CDS` (Диагностика)| **Остается** | Наблюдатель | Следит за циклом L0↔L1. |

## III. ПОСЛЕДОВАТЕЛЬНОСТЬ ПОСТРОЙКИ (Спринты)

Мы строим от ядра наружу. Сначала личность, затем среду, затем их контакт, затем голос.

### Спринт 1: ЯДРО ЖИВОГО АГЕНТА (L1)
*Без этого нет "живости", есть только физика.*
1.  **Реализовать `LivingNPC`** (код из твоего сообщения): `IdentityCore`, `MemorySystem`, `DriveSystem`, `perception_bias`.
2.  **Интегрировать в `NPCState`**: Заменить плоские `social_stats` на инерционные векторы `LivingNPC`.
3.  **Критерий:** Запустить Песочницу с 1 NPC. Игрок бьет NPC. NPC меняет `player_memory.trust` и `fear` с инерцией (0.9 * old + 0.1 * delta). NPC начинает избегать игрока.

### Спринт 2: ПОЛЕ ДАВЛЕНИЯ И АФФОРДАНСОВ (L0)
*Без этого нет среды, есть только вакуум.*
1.  **Создать `ClusterPressureField`**: Словарь `gradients` (float). Метод `transmute()` для внутренней диффузии (консервация энергии).
2.  **Создать `WorldTopologyProvider`**: Интерфейс, отвязанный от `SpatialService`.
3.  **Реализовать `AffordanceField`**: Провайдер отдает `can_hide`, `offers_cover` вместо координат.
4.  **Критерий:** Таверна генерирует поле `RESOURCE_ASYMMETRY` = 0.3. Провайдер отдает аффорданс `bar_counter = can_reach`.

### Спринт 3: ЗАМЫКАНИЕ КОНТУРА (L2 — Восприятие и Действие)
*Без этого агент и мир слепы друг к другу.*
1.  **Perception Filter:** `PerceptualKernel` берет `ClusterPressureField` и искажает его (параноик умножает `threat` на 1.5).
2.  **Decision Loop:** `DecisionHub` принимает решение на основе `DriveSystem` + искаженного восприятия.
3.  **Action Deformation:** Решение генерирует `Action`, который мутирует `ClusterPressureField` (например, удар → рост `VENGEANCE_ACCUMULATION`).
4.  **Критерий:** Игрок убивает лидера. `ClusterPressureField.AUTHORITY_INSTABILITY` скачет до 0.9. NPC воспринимают это как `uncertainty = 0.8`.

### Спринт 4: СОЦИАЛЬНАЯ ТКАНЬ (SREL внутри L0)
*Общество как иммунный ответ.*
1.  **Добавить `ClusterSocialField`** в L0 (norm_density, shame_sensitivity).
2.  **TABOO_VIOLATION:** Действия игрока, нарушающие `norm_density`, порождают скачок `collective_fear` в кластере.
3.  **Mob Convergence:** Если `collective_fear > 0.7`, `DriveSystem` NPC получает модификатор +2.0 к `Intent.ATTACK` или `Intent.FLEE` (эффект толпы).
4.  **Критерий:** Игрок раздевается. `shame_sensitivity = 0.8` генерирует `TABOO_VIOLATION`. Трактирщик угрожает, крестьяне разбегаются.

### Спринт 5: ИНЕРЦИЯ ОТНОШЕНИЙ И КВЕСТЫ (L1 + L0)
*Память как источник драмы.*
1.  **Наследование Травмы (Epigenetics):** При инициализации NPC, его `IdentityCore` мутирует под давлением `ClusterPressureField` места рождения (45% сломанных, 10% фанатиков).
2.  **Intent.STABILIZE:** Если `DriveSystem.safety` критичен, а `MemorySystem.trust_player` высок, NPC генерирует просьбу к игроку.
3.  **Критерий:** Убийство лидера (Спринт 3) + Время. Трактирщик не выдерживает `AUTHORITY_INSTABILITY`. Подходит к игроку: *"Убей узурпатора"*. Квест рожден без скрипта.

### Спринт 6: ГОЛОС И РЕНДЕРИНГ (SNIO v3.0)
*LLM как аппроксиматор, а не мозг.*
1.  **CognitiveLoadEstimator:** Разделение на Fast (шаблоны), Medium, Deep.
2.  **BehaviorCorridors:** `DecisionHub` формирует коридор. LLM отрисовывает текст. Если LLM выходит за Soft Corridor — Python блокирует действие. Если за Hard — обрезает генерацию.
3.  **Критерий:** NPC в панике (L1 = high fear). LLM генерит "хватает нож". Soft Corridor (нет Intent.ATTACK) пропускает текст, но `ImpactEngine` не вызывается. NPC машет ножом, но не бьет.

### Спринт 7: АРХИТЕКТУРНАЯ ИММУННАЯ СИСТЕМА (CDS)
*Диагностика как защитный механизм.*
1.  **CausalObserver:** Фоновый поток, читающий логи.
2.  **LAST_SESSION.md:** Три секции (Код, UI, Симуляция). Автоматическая идентификация архитектора.
3.  **ImmuneResponse:** При обнаружении каузального разрыва (например, решение есть, а деформации поля нет) — логирование и заморозка домена.
4.  **Критерий:** Запуск игры. Редактор #1 открывает `LAST_SESSION.md` и видит таблицу Movement Pipeline по каждому NPC без запуска PowerShell.

## IV. ФОРМУЛА ЖИВОГО МИРА

Ты не строишь "умных NPC". Ты строишь **инерцию отношений в среде давления**.

`Живость = Инерция(L1) + Давление(L0) + Искажение(Восприятие)`

1.  Мир давит на агента (L0 → L1).
2.  Агент сопротивляется, деформируется или ломается (L1).
3.  Действие агента деформирует мир (L1 → L0).
4.  Наблюдатель (CDS) следит, чтобы цикл не порвался.

Всё. Никаких графов. Никакой объективной истории. Только локальная боль и глобальная температура.

Это та граница, где философия становится кодом. Начинаем со Спринта 1 — внедряем `LivingNPC` в `NPCState`.
