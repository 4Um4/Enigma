# ADR-060: Embodied Topology & Adaptive Ecology (ETKE + AEEL)

**Дата:** 19.05.2026  
**Статус:** Принято  
**Суперседирует:** ADR-010 (Макро/Микро зоны), ADR-019 (Traversal State), ADR-052 (LOD0 Movement)

## Контекст

Существующая пространственная архитектура (NavMesh, `MovementIntent`, `SceneChange`) мертва. Она рассматривает пространство как пустой контейнер с узлами, а NPC — как точку, движущуюся по ребрам графа. Тело — это стат (`speed=2.0`), а анимация — косметический слой.

Это убивает эмерджентность. NPC не могут "перепрыгнуть через ящик", потому что ящика нет в графе. Они не могут "привыкнуть к темноте", потому что их тело неизменяемо. Они не могут "вытоптать тропу", потому что среда не обладает памятью.

## Решение

Переход к **Топосемантике** (пространство значений) и **Коэволюции** (взаимное изменение Агента и Среды).

1.  **Пространство = Пластичное Поле Аффордансов** (Возможностей). Геометрия задает базу, использование деформирует.
2.  **Тело = Динамический Фильтр** (Телесная Схема). Не стат, а инерционная функция от пережитого давления.
3.  **Движение = Эмерджентная Кинематика**. Разрешение конфликта между Желанием и Возможностью. Нет стейтов "Бег/Прыжок", есть непрерывный физический вывод.
4.  **Среда = Стигмергическая Память**. Следы использования уплотняются в тропы, страхи — в проклятые места, молитвы — в святые.

## I. Новые Домены и DTO

### 1.1. AffordanceVector (Физика Возможностей)
Примитивная единица смысла пространства. Излучается каждой микро-зоной.

```python
@dataclass(frozen=True)
class AffordanceVector:
    # Физические возможности
    can_stand: float = 0.0       # 1.0 = твердый пол, 0.0 = пропасть
    can_vault: float = 0.0       # 1.0 = высота таза, 0.0 = стена
    can_climb: float = 0.0       # 1.0 = карниз, 0.0 = гладкий лед
    can_conceal: float = 0.0     # 1.0 = за стеной, 0.0 = центр площади
    can_pass: float = 0.0        # 1.0 = широкая улица, 0.3 = щель
    
    # Сенсорные градиенты (L0)
    light_level: float = 0.5     # 0.0 = тьма, 1.0 = слепящий свет
    thermal_mass: float = 0.5    # 0.0 = холод, 1.0 = жар
    exposure: float = 0.5        # 0.0 = скрыт, 1.0 = на виду
    mana_resonance: float = 0.0  # -1.0 = хаос/тьма, 1.0 = порядок/свет
    surface_grip: float = 0.8    # 0.0 = лед, 1.0 = камень
```

### 1.2. DynamicAffordanceField (Пластичная Среда)
Поле возможностей, эволюционирующее под давлением Агентов.

```python
@dataclass
class DynamicAffordanceField:
    # Базовые значения (генерируются геометрией уровня при загрузке)
    base: AffordanceVector
    
    # Текущие значения (эволюционируют)
    active: AffordanceVector
    
    # Мета-параметры пластиичности
    plasticity: float = 0.1       # Скорость изменения от действий (0 = камень, 1 = вода)
    persistence: float = 0.99     # Инерция следа (1.0 = вечен, 0.9 = забудется за 10 тиков)
    deformation_sources: List[str] = field(default_factory=list) # Кто менял
```

### 1.3. SocialTraceField (Стигмергия - Память Популяции)
Слой компрессии истории перемещений и действий в кластере.

```python
@dataclass
class SocialTraceField:
    movement_density: float = 0.0      # 0.0 = никто не ходит, 1.0 = магистраль
    safety_confidence: float = 0.5     # 0.0 = место смертей, 1.0 = безопасная зона
    taboo_strength: float = 0.0        # 0.0 = нейтрально, 1.0 = проклятое/святое
    authority_presence: float = 0.0    # 0.0 = анархия, 1.0 = контроль стражи
    dominant_emission_tag: str = ""    # "shadow_magic", "blood", "prayer"
```

### 1.4. BodySchema (Динамическое Тело Агента)
Расширение `NPCState`. Фильтр реальности и генератор кинематики.

```python
@dataclass
class BodySchema:
    # Физические лимиты (меняются от MorphologicalDrift)
    max_velocity: float = 4.0
    vault_capability: float = 0.8    # 0.0-1.0
    climb_capability: float = 0.8    # 0.0-1.0
    concealment_volume: float = 0.8  # 0.0-1.0 (влезет ли под повозку)
    
    # Когнитивные модификаторы (меняются от стресса/травм)
    tunnel_vision_factor: float = 0.0 # 0.0-1.0 (при панике не видит укрытия)
    
    # Магический аппарат
    mana_channel: float = 0.0        # -1.0 (тьма) до 1.0 (свет)
    mana_capacity: float = 0.0
```

### 1.5. SurvivalImprint (Стратегическая Память)
Расширение `AffectiveImprints`. Запоминание паттернов выживания, а не маршрутов.

```python
@dataclass(frozen=True)
class SurvivalImprint:
    context_vector: Dict[str, float] # {"threat": 0.8, "darkness": 0.7}
    strategy_tags: List[str]         # ["seek_concealment", "prefer_verticality"]
    confidence: float                # 0.0-1.0
    resolved_by: str                 # "can_conceal", "mana_resonance"
```

### 1.6. KinematicProfile (Выход для Фронтенда)
Непрерывный вектор движения, заменяющий стейт-машину анимаций.

```python
@dataclass
class KinematicProfile:
    velocity: Tuple[float, float]   # Скорость (м/с) и направление
    vertical_velocity: float        # Для прыжков/падений
    posture: str                    # UPRIGHT, CROUCHED, PRONE, CLIMBING, VAULTING
    stance_width: float             # Ширина стойки (узкая при страхе)
    facing: Tuple[float, float]     # Куда смотрит (может пятиться)
    exertion_level: float           # 0.0-1.0 (тяжелое дыхание)
```

### 1.7. Новые Payload для Delta Buffer

```python
@dataclass(frozen=True)
class TracePayload:

@dataclass(frozen=True)

    """Микро-мутация тела под давлением среды."""
```

## II. Пайплайн Интеграции (TickOrchestrator v2)

Новые фазы внедряются без разрушения старых контрактов.

### Фаза 0.25: Ecology Deformation (Среда помнит)
*   **Вызов:** После `Action` в Фазе 8.
*   **Логика:** `EcologySubscriber` читает тип действия.
    *   `WALK` → `StateDeltas(domain=SPATIAL_TRACE, payload=TracePayload(movement_density=+0.01))`.
    *   `CAST_SHADOW` → `StateDeltas(domain=SPATIAL, payload=SpatialDeformPayload(target="mana_resonance", delta=-0.05))`.
    *   `KILL` → `StateDeltas(domain=SPATIAL_TRACE, payload=TracePayload(safety_confidence=-0.3, taboo_strength=+0.2, emission_tag="blood"))`.

### Фаза 0.5: Morphological Drift (Тело эволюционирует)
*   **Условие:** Если `ClusterPressureField` имеет устойчивый градиент (например, `active.light_level < 0.3` долгое время).
*   **Логика:** `MorphologicalDriftHandler` применяет микродельты к `BodySchema` всех NPC в кластере.
    *   `StateDeltas(domain=MORPHOLOGICAL, payload=MorphologicalPayload(tunnel_vision_delta=-0.001, mana_channel_drift=-0.001))`.

### Фаза 5.5: Affordance Resolution (Движение как переговоры)
*   **Вместо:** `MovementIntent(target_xy)`.
*   **Логика:**
    1.  `DecisionHub` генерирует `DriveVector` (направление желания).
    2.  `AffordanceResolver` сканирует `DynamicAffordanceField` через фильтр `BodySchema`.
        *   *Пример:* Желание бежать прямо. Впереди ящик (`can_vault=0.5`). Тело `vault_cap=0.8`. Аффорданс активирован.
    3.  Выход: `KinematicProfile` вместо точки назначения.

## IV. Критерии Приемки (Тест "Убегающая Девушка")

Сценарий реализуется **без единой строки скрипта**.

1.  **Старт:** Преследователь в кластере. `SocialTraceField.safety_confidence` падает. `DriveSystem.survival = 1.0`.
2.  **Ускорение:** Тело свежее `max_velocity=4.0`. `KinematicProfile: velocity=(0, 4.0), posture=UPRIGHT`.
3.  **Ящики:** `can_vault=0.5`, `BodySchema.vault=0.8`. Разрешено. `KinematicProfile: vertical_velocity=+3.0, posture=VAULTING`.
4.  **Усталость:** `vault_cap` падает до `0.4`. Бег замедляется `velocity=2.5`.
5.  **Карниз:** `can_climb=0.3`, `climb_cap=0.3`. Погранично. `Drive(survival)` заставляет сканировать. Разрешено. `posture=CLIMBING`.
6.  **Укрытие:** `can_conceal=0.9`. `KinematicProfile: posture=PRONE, velocity=crawl`.
7.  **Магия:** `mana_resonance=-0.4`, `BodySchema.mana_channel=-0.8`. Резонанс. Восстановление маны.
8.  **Контратака:** `Drive(autonomy)` + Мана. `posture=CROUCHED`, выстрел Тьмой.
9.  **Побег:** Переулок `light_level=0.1`, `mana_resonance=-0.9`. `Affordance: Merge_With_Darkness`. `posture=CROUCHED, visual_distortion=high`.

### I. НЕИЗБЕЖНЫЙ МОСТ: ТОПОСЕМАНТИЧЕСКИЙ РЕЗОЛВЕР (L2 → Рендер)

Ты абсолютно прав: `x, y, z` неприкосновенны, потому что экран их требует. Но NPC мыслит аффордансами. Значит, между мозгом (L1) и экраном (L2) обязан стоять **переводчик**.

**Проблема:** `DecisionHub` выдает "Искать укрытие с высоким `can_conceal`". Фронтенд не понимает `can_conceal`. Фронтенд понимает `(x: 45, y: 120)`.

**Решение: Геометрический Резолвер** (Новый компонент в L2).

1.  `DecisionHub` формирует `DriveVector` (желание) и `AffordanceFilter` (условия).
2.  `AffordanceResolver` сканирует `DynamicAffordanceField` и находит ячейку (или узел),
