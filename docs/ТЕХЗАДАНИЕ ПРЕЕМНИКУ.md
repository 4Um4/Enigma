## 1.1 AffordanceVector (ОБЯЗАТЕЛЬНО)

```python
class AffordanceVector:
    # Физические возможности (Моторика)
    can_stand: float = 0.0
    can_vault: float = 0.0
    can_climb: float = 0.0
    can_conceal: float = 0.0
    can_pass: float = 0.0

    # Кинематическое сопротивление
    surface_grip: float = 0.8
    drag_coefficient: float = 0.0

    # Сенсорные градиенты (L0)
    light_level: float = 0.5
    thermal_mass: float = 0.5
    exposure: float = 0.5
    mana_resonance: float = 0.0
```

# ⚙️ 2. НОВЫЕ СИСТЕМНЫЕ КОМПОНЕНТЫ

## 2.1 SteeringResolver (ОБЯЗАТЕЛЬНО)

Функция:

* DriveVector → velocity
* учитывает:

  * AffordanceVector
  * BodySchema
  * obstacle forces
  * drag

---

## 2.2 MotionIntegrator (ОБЯЗАТЕЛЬНО)

```text
position += velocity * dt
velocity += acceleration * dt
```

Дополнительно:

* stamina decay
* grip influence
* braking vs acceleration logic

---

## 2.3 Interaction Kernel (НОВЫЙ СЛОЙ L2)

### Операции:

```text
PICK(object_id)
DROP(object_id)
CARRY(object_id)
USE(object_id)
```

### Важно:

* НЕ физическая симуляция
* только привязка/перепривязка состояния

---

## 2.4 WorldTopologyProvider (ЕДИНЫЙ ИНТЕРФЕЙС МИРА)

```python
class WorldTopologyProvider:
    query_affordance_field(region, body)
    query_cluster_trace(region)
    apply_deformation(region, payload)
```
