3. Отсутствие метрик баланса → Критически подтверждено
decision_hub.py использует ~20+ констант из constants.py. Формула score имеет 8 измерений: drive + emotion + rel_mod - risk_penalty + inertia + noise + mask_mod + opportunity.
При fear=0.8, risk=0.9, mask=COLLAPSE, opportunity=0.6 score может уйти в -2.0 или +3.0 непредсказуемо. Без симулятора ты крутишь ручки вслепую. Это убьёт месяцы.
4. Рост когнитивной нагрузки → Подтверждено архитектурой
_pipeline() делает всё: тики → физику → экономику → социальные слухи → рефлексы → решения → вербализацию → память → коммит.
Чтобы добавить одну механику (например, "яд" или "подкуп"), тебе нужно тронуть 6 блоков в одном файле, не сломав порядок мутаций. Это путь к выгоранию и регрессиям.
