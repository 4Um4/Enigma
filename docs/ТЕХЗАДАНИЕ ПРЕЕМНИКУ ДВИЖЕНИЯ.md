## 1. ЧТО СДЕЛАНО В S85 (Кумулятивно)

1. **Semantic Spatial Binding (Фаза 1 - ЗАВЕРШЕНА):**
   - В `LifeEngine._resolve_position` внедрён локальный `_ACTIVITY_TO_ROLE_MAP`.
   - Метод теперь вызывает `SpatialService.resolve_node(role=NodeRole)`, получая валидный `NodeRef`.
   - Убит фоллбэк в несуществующий узел `"common_area"` и пустой `_DEFAULT_ACTIVITY_MAP`.
   - Доказано: API `resolve_node` УЖЕ существовал в `SpatialService`, разрыв был исключительно на стороне потребителя (`LifeEngine`).

2. **Архитектурное разделение: Архетип vs Индивид (Data Layer - ЗАВЕРШЕНО):**
   - Утверждён принцип: **Архетип = Профессия** (содержит только `schedule`), **Индивид = Должность** (содержит `activity_map` для кросс-локаций).
   - Из `maid.json` и `thief.json` удалён `activity_map` с захардкоженными координатами.
   - В `borko.json` добавлен корректный `activity_map` для выхода на `city_gate`.

3. **Археология и закрытие Bug Risk 999.0 (Фаза 2 - ЗАВЕРШЕНА):**
   - Доказано, что `radius=999.0` в `EventDTO` является латентным риском, но **не влияет** на визуальную фильтрацию (`_can_see` использует хардкод 15.0, игнорируя поле `radius`).
   - Зафиксировано как ADR-148 (отложенный риск для аудио-событий).

4. **Расширение SUPERBOX (Observability - ЗАВЕРШЕНО):**
   - В `drift_laboratory.py` добавлен режим `idle_simulation_stability` (1000 тиков).
   - Исправлена оптика теста: метрика `UNIQUE_NODES_VISITED` теперь читает `scene_state["npc_positions"]` (SSOT), а не кэш `LifeEngine`.

## 2. АРХЕОЛОГИЧЕСКИЕ ОТКРЫТИЯ (Зафиксированные факты)

1. **SpatialService API:** Метод `resolve_node(role: NodeRole, ...)` существовал и был полностью рабочим. Проблема была в том, что `LifeEngine` вызывал несуществующий `resolve_node(role=...)` с строковыми аргументами или падал в хардкод.
2. **GraphCompiler:** УЖЕ создавал правильный `alias_map` и присваивал `NodeRole` узлам при компиляции.
3. **Архетипы:** Хранили `activity_map` с привязкой к конкретным локациям (например, `"tavern_silver_wolf": "main_hall"`), что нарушало масштабируемость.
4. **EventDTO Radius:** Дефолтное значение `999.0` — "мертвый" параметр для визуальных событий, так как `perception_filter._can_see()` его не читает.
5. **JSON Mirror:** `scene_state_manager.py` всё ещё выступает файловым сервером для фронтенда.
6. **GameScreen Legacy:** Содержит каскады фоллбэков (`list → dict`, deprecated fields).
7. **Sprite Resolver:** Использует один спрайт для дверей, лестниц и бара.
