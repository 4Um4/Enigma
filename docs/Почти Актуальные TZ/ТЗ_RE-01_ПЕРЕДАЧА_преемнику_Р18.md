## 3. Активная задача преемника — Р18 «Адаптация»

### 3.1. Правило раунда (устав §12.2 v1.9, дословно GPT)

```text
НЕ ДОКАЗЫВАЕМ, ЧТО «АДАПТАЦИЯ СУЩЕСТВУЕТ».
ДОКАЗЫВАЕМ ИЛИ ОПРОВЕРГАЕМ, ЧТО ЕСТЬ КАУЗАЛЬНАЯ РАБОТА,
КОТОРУЮ НИКТО ДРУГОЙ В ENIGMA НЕ ВЫПОЛНЯЕТ.
```

### 3.2. Контур археологии (вскрыть весь причинный контур, не только слово adaptation)

```text
заявленный феномен → writer → что именно изменяется? → где хранится? → кто читает?
→ какое поведение меняет? → может ли тот же эффект возникнуть из уже утверждённых состояний + истории?
```

### 3.3. Три класса подозрительных остатков

1. **Толерантность к несовпадению** — отдельный механизм или изменение ожиданий / значимости / trust / удовлетворённости / decision-cost?
2. **Изменение со временем** — настоящая память адаптации или следствие накопления истории?
3. **Снижение/перенастройка реакции** — происходит ли что-то, не получаемое обычным обновлением уже существующих состояний?

### 3.4. Нож + обратная сторона (равнообязательны)

- **Р17-П1:** если поведение любящего человека после длительной совместной истории воспроизводится без `Adaptation` — уничтожается не поведение, а ложный владелец.
- **Обратная сторона:** если removal-test обнаружит устойчивый остаток — НЕ растворять в существующих механизмах ради чистоты архитектуры; выделить минимальную причинную работу, и только после этого решать: Class I / Class IV / операция над историей.

### 3.5. Формат досье (расширенный, дословно GPT)

```text
writer → state / stored fact → reader → causal effect → existing substitute
→ anti-Bond test → остаток → онтологический кандидат
```
