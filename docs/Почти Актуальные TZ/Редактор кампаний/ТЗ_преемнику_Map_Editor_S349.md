## 7. Процессные уроки серии S349 (оплачено кровью — не повторяй)

1. **Один пакет правок = один коммит.** Два параллельных пакета → D8-код уехал в D3-коммит;
   расхождение message↔содержимое не чинится без переписывания истории.
2. **Номер сессии вписывается ТОЛЬКО после записи в реестр** (греп MUTATIONS + `git log --all`).
   Моя коллизия S348 стоила ренумбера 18 live-ссылок.
3. Скрипты-миграции: **fail-loud по точным счётчикам ВХОЖДЕНИЙ** (`str.count`, не
   `Select-String` без `-AllMatches` — он считает строки, не вхождения); temp-файлы в `%TEMP%`,
   самоудаляются; одноразового кода в репо не оставлять.
4. Ручная правка >5 точек запрещена — только скрипт с вшитым эталоном и полной пост-проверкой
   (19 спрайт-правок легли скриптом без единого промаха).
5. Smoke + `ruff` перед каждым коммитом. Hook может упасть на ЧУЖОМ файле — тогда верифицируй
   свой коммит постфактум (`git show --stat HEAD`).
6. **Механика — Мастеру вопросами; архитектура и код — тебе.** Он принял в этой серии: еда =
   рантайм, владелец стойки = Торнин, дверь умирает со стеной, «дай удочку», камера 45°, ломаемые.
7. `.md` читается целиком; `.py` — точечными командами; терминал переполняется на больших
   выводах — пиши временные скрипты вместо многострочного `python -c` с кавычечной акробатикой.
