# ТЗ: «ТАВЕРНА СЕРЕБРЯНЫЙ ВОЛК» — Эпистемическая Симуляция с Моральным Измерением (v2.0)

**Версия:** 2.0 (расширенная) 
**Проект:** ENIGMA Mini-Game 
**Принцип:** Мир — это не загадка для разгадывания. Мир — это живой организм, который вы ранили своим присутствием.
**Контекст:** Это третье ТЗ в очереди. Оно опирается на автономный мир (ТЗ 1) и эмерджентный цикл деформации идентичности (ТЗ 2). Реализовывать только после замыкания каузальной цепочки "Нужда → Мнение → Изменение".

## 0. ФИЛОСОФСКИЙ КОНТЕКСТ (почему эта игра — не квест)

### 0.1. Главная ложь обычных игр
В обычной игре NPC — это функция. Игрок → диалог → награда → следующий NPC. NPC не помнит, не страдает, не меняется. Мир статичен между действиями игрока.

### 0.2. Главная истина ENIGMA
В ENIGMA нет NPC. Есть люди.
Люся — не «квестодатель с секретом». Она — 19-летняя девушка, которую били три года, которой угрожает гильдия воров, которая спит с кузнецом, потому что это единственное тепло в её жизни, и которая влюблена в стражника, который подглядывает за ней, не зная о её чувствах.
Если игрок сдаёт Люсю стражнику — она не «проваливает квест». Она умирает. Или сбегает. Или её находят в подвале с перерезанными венами. И Торнин, который молчал о её шпионаже из-за своего долга гильдии, — он тоже сломается. И Тень, который подозревал её, — он получит приказ устранить того, кто сдал её, потому что гильдия не прощает утечек.
Действие игрока — это камень, брошенный в пруд. Волны расходятся далеко.

### 0.3. Принцип «Нет злодеев»
Каждый NPC в ENIGMA пришёл к своей жизни через обстоятельства:

| NPC | Что он сделал | Почему | Моральная оценка |
|---|---|---|---|
| **Люся** | Шпионит для гильдии | Семью убили, гильдия подобрала на улице, у неё нет выбора | Жертва, ставшая соучастницей |
| **Тень** | Убил человека | Приказ гильдии, ему было 20, он не мог отказаться | Палач, ставший философом |
| **Борко** | Берёт взятки | 5 золотых в месяц при зарплате 12 — он кормит семью | Коррупционер из нужды |
| **Горан** | Ввозит контрабанду | Торговая гильдия душит налогами, он в долгах | Преступник из отчаяния |
| **Торнин** | Притворяется, что не знает о подвале | Должен гильдии 1200 золотых, если расскажет — умрёт | Трус, ставший соучастником |
| **Орм** | Выковал что-то для Торнина | Заплатили, не задавал вопросов, потом жена умерла | Ремесленник, продавший совесть |

Игрок не может сказать «он плохой, его надо наказать». Игрок может только сказать «я понимаю, почему он это сделал. И теперь я решаю, что с этим делать».

## 1. АРХИТЕКТУРА МОРАЛЬНОГО ИЗМЕРЕНИЯ

### 1.1. Три слоя последствий

**СЛОЙ 1: НЕПОСРЕДСТВЕННЫЙ (Direct Consequence)**
Игрок действует → NPC реагирует (trust, fear, stress меняются).

**СЛОЙ 2: СОЦИАЛЬНЫЙ (Social Ripple)**
NPC реагирует → другие NPC замечают → их отношения меняются.
*(Люся стала бояться игрока → Тень замечает это → Тень подозревает игрока)*

**СЛОЙ 3: СУДЬБИННЫЙ (Fate Consequence)**
Накопленные изменения → NPC принимает судьбоносное решение.
*(Люся не выдерживает давления → сбегает / сдаётся / кончает с собой)*

### 1.2. Social Fabric Matrix (Матрица социального ткани)
Это НЕ просто trust/fear к игроку. Это полная матрица NPC→NPC отношений.

```python
@dataclass
class SocialFabric:
    """Полная матрица отношений всех NPC друг к другу.
    Не только player→NPC, но и NPC→NPC.
    Отслеживает ИЗМЕНЕНИЯ от начала сцены до выхода.
    """
    # Начальный снимок (при входе в таверну)
    baseline: Dict[Tuple[str, str], RelationshipSnapshot]
    # Текущий снимок (обновляется каждый тик)
    current: Dict[Tuple[str, str], RelationshipSnapshot]
    # История изменений (кто, когда, почему)
    deltas: List[RelationshipDelta]

@dataclass(frozen=True)
class RelationshipSnapshot:
    """Снимок отношений между двумя NPC в момент времени."""
    source_id: str # кто чувствует
    target_id: str # к кому
    trust: float   # -100..100
    fear: float    # 0..100
    affection: float # -100..100
    debt: float    # -100..100
    respect: float # 0..100

    @property
    def stability(self) -> float:
        """Стабильность отношений. Высокая = прочная связь."""
        return (abs(self.trust) + self.respect) / 2

    @property
    def tension(self) -> float:
        """Напряжение в отношениях."""
        return (self.fear + max(0, -self.trust) + max(0, -self.affection)) / 3

@dataclass
class RelationshipDelta:
    """Одно изменение отношений."""
    tick: int
    source_id: str
    target_id: str
    trust_delta: float
    fear_delta: float
    affection_delta: float
    cause: str # "player_action:blackmail", "npc_event:witnessed_violence", "rumor"
    description: str # "Люся начала бояться игрока после угрозы шантажом"
```

### 1.3. NPC→NPC динамика (не только player→NPC)
Ключевое: отношения между NPC меняются НЕ ТОЛЬКО от действий игрока, но и от их собственного взаимодействия.

**Примеры:**
- Если игрок раскрывает Люсе, что Борко подглядывает → `affection(lusya→borko)` падает на `-40`.
- Если игрок рассказывает Тени, что Горан сдал контрабанду → `fear(shadow→goran)` растёт, `trust` падает → Тень может убить Горана.
- Если игрок мирит Торнина и Люсю (через диалог) → `trust(tornin→lusya)` растёт → Торнин может защитить её от гильдии.

Игрок — это не центр мира. Игрок — катализатор.

## 2. СИСТЕМА МОРАЛЬНЫХ ДИЛЕММ

### 2.1. Dilemma Engine

```python
@dataclass
class MoralDilemma:
    """Моральная дилемма, возникающая из каузальной сети."""
    dilemma_id: str
    trigger_condition: str # когда дилемма активируется
    sides: List[DilemmaSide] # 2+ стороны
    consequences: Dict[str, List[FateConsequence]] # выбор → последствия
    philosophical_question: str # "Можно ли предать того, кого понимаешь?"

@dataclass
class DilemmaSide:
    """Одна сторона дилеммы."""
    label: str # "Защитить Люсю"
    description: str # "Утаить её секрет от стражи"
    npcs_affected: List[str] # кто выигрывает
    npcs_betrayed: List[str] # кто проигрывает
    moral_weight: float # 0..1, насколько тяжёлый выбор
    alignment_shift: Dict[str, float] # изменение фракционной лояльности

@dataclass
class FateConsequence:
    """Судьбинное последствие выбора игрока."""
    npc_id: str
    outcome: str # "death", "escape", "broken", "liberated", "empowered"
    description: str # "Люся сбегает через подвал. Ты больше никогда её не увидишь."
    cascade: List[str] # цепочка последствий для других NPC
    tick_delay: int # через сколько тиков наступает
```

### 2.2. Дилеммы миниигры (5 ключевых дилемм)

#### Дилемма 1: «Сдать или не сдать Люсю»
**Триггер:** Игрок раскрыл `lusya_basement` (знает о тайном ходе).
* **Сторона A — Сдать страже:**
  - Борко арестовывает Люсю.
  - Люся: `fate = imprisoned` → возможно казнена гильдией (silence).
  - Тень: `fear(shadow→player) = +60` → получает приказ устранить игрока.
  - Торнин: `trust(tornin→player) = -40` (он знал и молчал, теперь игрок сломал его молчание).
  - Орм: `grief(orm) += 30` (он любил Люсю).
  - *Философский вопрос:* Ты «спас» общество от шпионки. Но ты убил человека, у которого не было выбора.
* **Сторона B — Молчать:**
  - Люся: `trust(lusya→player) = +20`, `fear = -10`.
  - Тень: продолжает подозревать.
  - Борко: не знает.
  - *Философский вопрос:* Ты позволяешь преступлению продолжаться. Но ты даёшь человеку шанс сбежать.
* **Сторона C — Помочь сбежать:**
  - Люся: `fate = escaped` → исчезает из таверны.
  - Тень: `fury(shadow) = +80` → начинает охоту на игрока.
  - Торнин: `relief + guilt` → `stress += 20`.
  - Орм: `grief + anger` → может напасть на игрока.
  - *Философский вопрос:* Ты спас одного человека, но нажил врага, который убивает.

#### Дилемма 2: «Рассказать Тени о предателе»
**Триггер:** Игрок раскрыл `goran_contraband` и знает, что Тень ищет предателя.
* **Сторона A — Сдать Горана:** Горан: `fate = killed_by_guild`. Борко: `panic += 40`. *Вопрос:* Горан — контрабандист. Но он кормит семью. И его убийца — тоже не монстр.
* **Сторона B — Утаить:** Тень подозревает Люсю. Горан: `trust(goran→player) = +30`. *Вопрос:* Ты позволяешь гильдии воров продолжать террор. Но ты не стать палачом.
* **Сторона C — Предложить Горану защиту:** Горан: `trust = +50, fear = +30`. Тень: `suspicion(shadow→player) = +40`. *Вопрос:* Ты берёшь на себя ответственность за жизнь человека.

#### Дилемма 3: «Раскрыть Люсе, что Борко подглядывает»
**Триггер:** Игрок раскрыл `borko_voyeur`.
* **Сторона A — Рассказать Люсе:** Люся: `disgust(lusya→borko) = +80`. Борко: `shame = +50`. Орм: `anger(orm→borko) = +40`. *Вопрос:* Правда важнее комфорта?
* **Сторона B — Промолчать:** Люся продолжает любить Борко. *Вопрос:* Ты владеешь правдой, которая ранит. Имеешь ли ты право её скрыть?
* **Сторона C — Шантажировать Борко:** Борко: `fear(borko→player) = +50`. *Вопрос:* Ты используешь чужой грех для своей выгоды. Чем ты лучше?

#### Дилемма 4: «Долг Торнина»
**Триггер:** Игрок раскрыл `tornin_debt` и `tornin_basement`.
* **Сторона A — Помочь выплатить долг:** Игрок тратит деньги. Торнин: `trust = +40, stress = -20`. Тень: `anger = +50`. *Вопрос:* Ты освобождаешь одного человека от долга, но наживаешь врага в гильдии.
* **Сторона B — Использовать долг:** Торнин: `fear = +40`. *Вопрос:* Ты становишься тем, от кого Торнин бежал — новым кредитором.
* **Сторона C — Рассказать Борко:** Борко: `duty_conflict`. *Вопрос:* Ты заставляешь другого человека делать твой грязный выбор.

#### Дилемма 5: «Присоединиться к гильдии воров»
**Триггер:** Игрок раскрыл 3+ секрета, связанных с гильдией, и имеет `trust(shadow→player) >= 20`.
* **Сторона A — Вступить:** Тень: `trust = +30`. Борко: `duty = -50`. *Вопрос:* Ты становишься частью системы, которая давила Люсю.
* **Сторона B — Отказать:** Тень: `respect = +10, trust = -10`. *Вопрос:* Ты остаёшься чист. Но мир не меняется.
* **Сторона C — Согласиться, но сдать страже:** Риск: если Тень узнает → `fate(player) = threatened`. *Вопрос:* Где граница между ложью ради добра и просто ложью?

## 3. СИСТЕМА СУДЬБИННЫХ ПОСЛЕДСТВИЙ (Fate Engine)

### 3.1. FateTracker

```python
@dataclass
class FateState:
    """Судьба NPC — кумулятивный результат всех воздействий."""
    npc_id: str
    stability: float # 0..1, насколько устойчива жизнь NPC
    threat_level: float # 0..1, насколько близок к катастрофе
    bonds: Dict[str, float] # npc_id → strength of bond (0..1)
    secrets_exposed: List[str] # какие секреты раскрыты
    fate_trajectory: str # "stable", "deteriorating", "improving", "critical"
    pending_fate: Optional[str] # "escape", "death", "broken", "liberated"
    fate_tick: Optional[int] # когда наступит

class FateTracker:
    """Отслеживает судьбинные траектории всех NPC."""
    def update(self, tick: int, social_fabric: SocialFabric, secrets_exposed: Dict[str, bool]) -> None:
        for npc_id in ALL_NPCS:
            stability = self._compute_stability(npc_id, social_fabric)
            threat = self._compute_threat(npc_id, social_fabric, secrets_exposed)
            if threat > 0.8 and stability < 0.2:
                self._trigger_fate_event(npc_id, tick)
```

### 3.2. Fate Events

```python
@dataclass
class FateEvent:

```


### 5.2. Цветовая система
* **Зелёный 🟢:** Отношения улучшились, судьба улучшена.
* **Красный 🔴:** Отношения ухудшились, судьба разрушена.
* **Жёлтый 🟡:** Без изменений, неопределённость.
* **❤️:** Сильное ухудшение (предательство, ненависть).
* **💀:** Смерть, необратимая потеря.

### 7.1. Последние слова NPC

```python
    TORNIN_BROKEN = "Таверна... она не моя. Она — их. Я просто стою за стойкой."
```

> *Он сидел в кузнице, глядя на молот.*
> *Ты знаешь, что он винит тебя.*
> *Ты знаешь, что он прав.)*

## 8. СИСТЕМА ВНУТРЕННИХ ДИЛЕММ ИГРОКА

### 8.1. Cognitive Dissonance Tracker

```python
@dataclass

    """Внутреннее состояние игрока — не персонажа, ИГРОКА.

    """

    """Противоречие в действиях игрока."""

    action_b: str # "Сдал Горана Тени"

    emotional_weight: float # 0..1
```

### 8.2. Противоречия, которые видит система

| Пожалел Люсю | Напал на Борко | Ты пожалел жертву и стал насильником |

### 8.3. Влияние на End-Screen
Если у игрока 3+ противоречия:

## 10. ПРИНЦИПЫ (финальные)

1. Мир — не загадка. Мир — живой организм.
2. Нет злодеев. Есть люди, сломленные обстоятельствами.
3. Каждое действие — камень в пруду. Волны расходятся.
4. Игрок не решает квест. Игрок выбирает, кем быть.
5. Тишина — сильнее слов. Не каждый NPC скажет «спасибо» или «проклинаю».
6. Судьбы необратимы. Мёртвый Горан не вернётся.
7. Мир помнит. Следующая сессия начнётся с последствиями этой.
8. Моральная дилемма — не выбор A/B. Это выбор, который ты носишь с собой.
9. End-screen — не счёт. Это зеркало. Ты видишь, кем стал.
10. Replay — не повторение. Это «а что, если бы я выбрал иначе?»
