## 2. ПРОТИВОРЕЧИЯ И РАССИНХРОНИЗАЦИИ

### 2.1 ⚠️ ПРОТИВОРЕЧИЕ #1: Номера спринтов не совпадают с текущим состоянием

**Факт:** 
```
ТЕХЗАДАНИЕ ВОЛИ = "Спринт 29"
ТЕХЗАДАНИЕ UI = "Спринт 31"
ТЗ_CDS = "Спринт 39"
Но реальность: R4 активен сейчас, R7 следующий
```

**Проблема:** Файлы написаны в разные моменты времени. Спринт-нумерация устарела.

**Действие:**
- ✅ **ПЕРЕПИСАНО**: Все спринты переделаны относительно текущего R4
- 📄 `ROADMAP_v2.0_RATIONALIZED.md` — новая дорожная карта с актуальными номерами

**Почему произошло:** Параллельная разработка нескольких документов без синхронизации временных шкал.

---

### 2.2 ⚠️ ПРОТИВОРЕЧИЕ #2: ТЕХЗАДАНИЕ ВОЛИ содержит философию + ТЗ + баги в одном файле

**Структура (нарушена):**
```
Строки 1–150:     Философия (трубопровод воли, постулаты)
Строки 150–400:   Исполняемые ТЗ (трубопровод, интеграция)
Строки 400–500:   Известные баги (DirectiveSubscriber, [DIRECTIVE_NO_STATE])
```

**Проблема:** Невозможно отличить, что закон, что ТЗ, что известный баг.

**Действие:**
- ✅ **ФИЛОСОФИЯ** → `00_CAUSAL_CONTRACT_v2.0.md` (§ 1–3)
- ✅ **ТЗ** → оставить отредактированным в `ТЕХЗАДАНИЕ_ПРЕЕМНИКУ_ВОЛИ.md` или выделить новый файл
- ✅ **БАГИ** → `03_KNOWN_ISSUES_AND_BUGS.md` (BUG-001, BUG-002 и т.д.)

**Почему произошло:** Файл писался одновременно как архитектурный манифест и исполняемый план. Нужна разделение.

## 8. РЕКОМЕНДАЦИИ ДЛЯ WORKFLOW

### Для архитектора спринта

1. **Начни с** `00_CAUSAL_CONTRACT_v2.0.md` (закон)
2. **Затем прочитай** `ROADMAP_v2.0_RATIONALIZED.md` (план)
3. **Выбери спринт**, откройи соответствующий ТЗ
4. **Проверь** `03_KNOWN_ISSUES_AND_BUGS.md` (что может сломаться)
5. **Выполни PowerShell команды** в ТЗ (синхронизация реальности)
6. **Начинай кодить**

### Для LLM-кодера

1. **Требование:** CAUSAL_CONTRACT v2.0 + соответствующее ТЗ
2. **Перед кодом:** PowerShell синхронизация (обязательна)
3. **После кода:** Регрессионный тест (tests/sandbox/)
4. **При проблеме:**查 KNOWN_ISSUES_AND_BUGS.md
5. **После спринта:** Обновить статусы в ROADMAP

### Для диагностики

1. **CDS работает параллельно**, не блокирует
2. **При странном поведении:** Ищи в KNOWN_ISSUES (есть ли известный баг?)
3. **При архитектурном вопросе:** CAUSAL_CONTRACT — источник истины
