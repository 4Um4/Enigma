## 📍 НАЧНИ ОТСЮДА (Start Here)

### Ты архитектор спринта?
1. Прочитай **00_CAUSAL_CONTRACT_v2.0.md** (30 мин) — это закон
2. Прочитай **ROADMAP_v2.0_RATIONALIZED.md** (20 мин) — план спринтов
3. Выбери свой спринт, откройи соответствующее ТЗ
4. Прочитай **AUDIT_CLEANUP_AND_RECOMMENDATIONS.md** (10 мин) — понимание истории

### Ты LLM-кодер, ищешь что делать?
1. Прочитай **ROADMAP_v2.0_RATIONALIZED.md** (где ты в плане?)
2. Откройи ТЗ своего спринта
3. **КРИТИЧНО:** Выполни PowerShell команды из ТЗ (синхронизация реальности)
4. Если что-то странно → **KNOWN_ISSUES_AND_BUGS.md**

### Ты ловишь баг?
1. Открой **KNOWN_ISSUES_AND_BUGS.md** (ищи по названию бага)
2. Если не найдешь → проверь **CAUSAL_CONTRACT_v2.0.md** (§ 4, Запреты)
3. Если вопрос архитектурный → **CAUSAL_CONTRACT_v2.0.md** (§ 1–3, Философия)

```

  ↓ (Выполни команды из ТЗ)

```

### Если ты закончил спринт

**Checklist завершения:**
```
[ ] Написал регрессионные тесты (tests/sandbox/)
[ ] Очистил __pycache__ перед commit
[ ] Обновил статус в ROADMAP_v2.0
[ ] Если нашел новый баг → добавил в KNOWN_ISSUES_AND_BUGS.md
[ ] Все запреты из CAUSAL_CONTRACT соблюдены?
```

### Если что-то странно работает

**Алгоритм диагностики:**
```
1. Прочитай CAUSAL_CONTRACT_v2.0.md § 2 (Единые источники истины)
2. Найди, нарушаешь ли ты какой-то запрет (§ 4)
3. Найди баг в KNOWN_ISSUES_AND_BUGS.md
4. Если ничего не помогло → сообщи и добавь новый баг
```

## 📝 ЕСЛИ НУЖНО ДОБАВИТЬ НОВОЕ ТЗ

1. Прочитай **ROADMAP_v2.0_RATIONALIZED.md** (раздел "Структурирование папок")
2. Создай файл в правильной папке: `docs/R[N]_NAME/ТЗ_*.md`
3. **Обязательно:** Добавь в заголовок:
   - Спринт (R7, R8 и т.д.)
   - Зависимости (что должно быть готово)
   - Блокирует (что ждет этого)
   - ТЗ (ссылка на этот документ)
4. В конце добавь PowerShell команды для синхронизации реальности
5. Обнови ROADMAP_v2.0
