## СЛОЙ 1: НАДСТРОЙКИ (опциональны, можно отключить)

### ❌→✅ TemporalDomain — правильная форма — 9/10

**v3.0 ошибка:** TemporalDomain как отдельная онтология

```python
# НЕПРАВИЛЬНО:
class TemporalDomain(Enum):
    REACTIVE
    SITUATIONAL
    ADAPTIVE
    STRUCTURAL
```

Это создает параллельную реальность.

**v2.1 ошибка:** TemporalDomain убит полностью

```python
# НЕПРАВИЛЬНО:
REACTIVE_UPDATE = 1
SITUATIONAL_UPDATE = 10
# Это просто расписание, теряет смысл
```

**Правильно: TemporalDomain как свойство состояния**

```python
class StateProperty:
    """Каждое состояние имеет временное поведение"""
    
    value: float
    
    # Когда это обновляется?
    update_frequency: int  # каждый тик, каждые 10, каждые 1000
    
    # Как быстро меняется?
    inertia: float        # 0.1 = легко меняется, 0.95 = упорно держится
    
    # Как восстанавливается?
    decay_rate: float     # В покое → базовое значение
    
    # Когда утрачивает актуальность?
    expiration_tick: int  # После этого = забыто

# Пример:
fear = StateProperty(
    value=0.8,
    update_frequency=1,        # Каждый тик может меняться
    inertia=0.2,               # Быстро меняется
    decay_rate=0.05,           # Быстро восстанавливается
    expiration_tick=current_tick + 50  # Забывается через 50 тиков
)

belief = StateProperty(
    value=0.6,
    update_frequency=1000,     # Очень редко меняется
    inertia=0.95,              # Упорно держится
    decay_rate=0.001,          # Медленно восстанавливается
    expiration_tick=current_tick + 100000  # Почти не забывается
)
```

**Преимущество:**
- TemporalDomain встроено в состояние, не отдельная онтология
- Можно отключить, система не рассыпется
- Естественно масштабируется новым состояниям

**Вероятность выжить через 2 года: 85%**

### ❌→✅ Ownership с источниками — 8.5/10

**v2.1 ошибка:** Монополия владельца

```python

# Никто кроме AffectiveIntegrator не может менять emotion
```

Это создает бутылочное горлышко.

**Правильно: Владелец + разрешённые источники**

```python
class StateOwnership:
    """Владелец состояния + разрешённые источники"""
    
    state_name: str = "emotion"
    owner: str = "EmotionState"  # Только этот может Apply
    
    # Но несколько источников могут предлагать изменения
    allowed_sources: List[str] = [
        "PerceptionPayload",     # Восприятие может влиять
        "MemoryPayload",         # Память может влиять
        "PredictionPayload",     # Ожидание может влиять
        "TraumaImprint",         # Травма может влиять
    ]
    
    def propose_mutation(self, source: str, delta: float) -> bool:
        if source not in self.allowed_sources:
            return False  # Отказать
        
        # Owner (EmotionState) примет решение о Apply
        return self.owner.consider_mutation(source, delta)
```

**Преимущество:**
- Владелец остаётся одним
- Но система не блокируется
- Много источников могут влиять на одно состояние

**Вероятность выжить через 2 года: 85%**

```python
class ExpectationModifier:
    """Ожидание не создаёт эмоцию, меняет восприятие"""
    
    def apply_expectation_lens(self, perception: PerceptionEvent) -> PerceptionEvent:
        """
        Ожидание меняет, как ты воспринимаешь события
        """
        
        # Если я жду угрозу:
        if self.expects_threat:
            # Нейтральный жест → интерпретирую как агрессию
            perception.salience *= 1.5
            perception.semantic_seed = self._reinterpret_as_threat(perception.semantic_seed)
        
        # Если я жду друга:
        elif self.expects_friend:
            # Вещи интерпретирую благожелательнее
            perception.salience *= 0.7
        
        return perception
    
    def compute_prediction_error(self, perception: PerceptionEvent) -> float:
        """
        Ошибка = surprise
        Surprise → AttentionWeight (не эмоция!)
        """
        error = abs(self.prediction_value - perception.actual_value)
        return error
    
    def affect_from_surprise(self, error: float) -> EmotionPayload:
        """
        Большая ошибка → ATTENTION SPIKE
        Не создаю эмоцию, только усиливаю внимание
        """
        if error > 0.7:
            return EmotionPayload(
                emotion="alert",  # Не fear, а alert
                intensity=error,
                source="prediction_error"
            )
        return None
```

**Преимущество:**
- Expectation не создает параллельную реальность
- Меняет только восприятие (линзу)
- Зависит от Perception, не конкурирует с ней

### ❌ PhaseSpace — нужно правильнее — 6/10

**Kami выявил:** PhaseSpace скрывает непрозрачность.

**Решение:** Использовать, но с attractor points (не свободная геометрия)

```python
class PersonalityPhaseSpace:
    """Архетипы как аттрактеры в пространстве"""
    
    # Оси остаются, но:
    fear_aggression: float      # -1 to +1
    submission_dominance: float # -1 to +1
    isolation_social: float     # -1 to +1
    
    # Но архетипы = ATTRACTOR POINTS (не свободные точки)
    ATTRACTOR_POINTS = {
        "BROKEN": (-0.9, -0.9, +0.1),
        "COWARD": (-0.8, -0.6, -0.2),
        "LEADER": (+0.7, +0.8, +0.6),
    }
    
    def get_dominant_archetype(self) -> str:
        """Какой аттрактор ближайший?"""
        current = (self.fear_aggression, self.submission_dominance, self.isolation_social)
        
        nearest = min(
            self.ATTRACTOR_POINTS.items(),
            key=lambda a: self._euclidean_distance(current, a[1])
        )
        return nearest[0]
    
    def shift_toward_archetype(self, target: str, magnitude: float):
        """Плавный сдвиг, но в сторону аттрактора"""
        target_point = self.ATTRACTOR_POINTS[target]
        
        # Не свободный сдвиг, а управляемое движение к аттрактору
        for i, (current, target_val) in enumerate(
            zip([self.fear_aggression, self.submission_dominance, self.isolation_social],
                target_point)
        ):
            new_val = current + (target_val - current) * magnitude
            # Клэмпинг, не выход за пределы [-1, +1]
            setattr(self, [...], max(-1.0, min(1.0, new_val)))
```

**Преимущество:**
- Архетипы — это аттрактеры, не произвольные точки
- Система имеет "гравитационные лунки"
- Поведение предсказуемо

**Вероятность выжить через 2 года: 65%**

```python
"""
Goal Factors: composable компоненты оценки целей.

Каждый фактор независим, инжектируется в GoalScorer.
R7: BeliefFactor, AffectFactor
R8: + MemoryFactor
R10: + PredictionFactor, SocialFactor
(без переписи GoalScorer)
"""

from typing import Protocol
from dataclasses import dataclass
from backend.app.models.npc.npc import NPC
from backend.app.models.npc.goals import Goal

@dataclass
class Contribution:
    """Вклад одного фактора в полезность цели."""
    name: str
    value: float

@dataclass
class DecisionContext:
    """Контекст принятия решения (может быть расширен)."""
    observer: NPC
    current_tick: int
    uncertainty: float = 0.0

# ============================================================================
# PROTOCOL
# ============================================================================

class GoalFactor(Protocol):
    """Один фактор, одна ответственность."""
    
    def contribute(
        self,
        goal: Goal,
        npc: NPC,
        context: DecisionContext
    ) -> Contribution:
        """Вычислить вклад этого фактора в полезность цели."""
        ...

# ============================================================================
# IMPLEMENTATIONS (R7)
# ============================================================================

class BeliefFactor:
    """Вклад убеждений в полезность цели.
    
    Если NPC верит, что цель опасна → полезность падает.
    Если верит, что цель нужна → полезность растет.
    """
    
    def contribute(
        self,
        goal: Goal,
        npc: NPC,
        context: DecisionContext
    ) -> Contribution:
        
        # Получить убеждение о цели
        belief_key = f"goal_{goal.type}"
        belief = npc.mind.epistemic.beliefs.get(belief_key)
        
        if not belief:
            return Contribution(name="belief", value=0.0)
        
        # Если цель критична для выживания
        if goal.type == "SURVIVE":
            # Убеждение в опасности повышает приоритет выживания
            contribution = belief.value * 0.15
        else:
            # Для других целей, убеждение может быть нейтральным
            contribution = (belief.value - 0.5) * 0.10
        
        return Contribution(name="belief", value=contribution)

class AffectFactor:
    """Вклад эмоций в полезность цели.
    
    Страх повышает приоритет выживания.
    Гнев повышает приоритет борьбы.
    """
    
    def contribute(
        self,
        goal: Goal,
        npc: NPC,
        context: DecisionContext
    ) -> Contribution:
        
        fear = npc.mind.affective.emotions.get("fear", 0.0)
        anger = npc.mind.affective.emotions.get("anger", 0.0)
        
        if goal.type == "SURVIVE":
            contribution = fear * 0.20
        elif goal.type == "COMBAT":
            contribution = anger * 0.15
        else:
            contribution = 0.0
        
        return Contribution(name="affect", value=contribution)

class MemoryFactor:
    """Вклад памяти (опыта) в полезность цели.
    
    Если цель часто удавалась → повышается приоритет.
    Если часто проваливалась → понижается приоритет.
    """
    
    def contribute(
        self,
        goal: Goal,
        npc: NPC,
        context: DecisionContext
    ) -> Contribution:
        
        # Получить историю успехов по этой цели
        success_rate = npc.mind.cognitive.memory.compute_success_rate(
            goal.type
        )
        
        # Успешные цели становятся приоритетнее
        contribution = success_rate * 0.15 - (1.0 - success_rate) * 0.10
        
        return Contribution(name="memory", value=contribution)

# ============================================================================
# AGGREGATOR
# ============================================================================

class GoalScorer:
    """Орхестратор факторов.
    
    Не знает про отдельные домены, только агрегирует вклады.
    """
    
    def __init__(self, factors: list):
        self.factors = factors
    
    def score(
        self,
        goal: Goal,
        npc: NPC,
        context: DecisionContext
    ) -> "GoalScore":
        """Вычислить GoalScore для цели."""
        
        contributions = {}
        
        for factor in self.factors:
            contrib = factor.contribute(goal, npc, context)
            contributions[contrib.name] = contrib.value
        
        # Агрегация: среднее арифметическое
        utility = (
            sum(contributions.values()) / len(contributions)
            if contributions
            else 0.0
        )
        
        # Зажать в [0, 1]
        utility = max(0.0, min(1.0, utility))
        
        return GoalScore(
            utility=utility,
            contributions=contributions,
            goal_type=goal.type
        )

@dataclass
class GoalScore:
    """Результат оценки цели."""
    utility: float  # 0.0-1.0
    contributions: dict  # {factor_name: value}
    goal_type: str
    reasoning: str = ""
    
    def __repr__(self):
        contrib_str = ", ".join(
            f"{k}:{v:.2f}" for k, v in self.contributions.items()
        )
        return f"GoalScore(utility={self.utility:.2f}, {contrib_str})"
```

```python
"""
Decision Hub: строит пространство решений (не выбирает).

Отделение от IntentSelector:
- DecisionHub = scorer (чистая функция)
- IntentSelector = chooser (может быть сложным)
"""

from dataclasses import dataclass
from typing import List, Tuple, Optional
from backend.app.models.npc.npc import NPC
from backend.app.models.npc.goals import Goal
from backend.app.services.decision.goal_factors import (
    GoalScore,
    GoalScorer,
    DecisionContext
)

@dataclass
class DecisionSpace:
    """Пространство всех возможных решений с их скорами."""
    candidates: List[Tuple[Goal, GoalScore]]
    context: DecisionContext
    
    def best(self) -> Optional[Tuple[Goal, GoalScore]]:
        """Лучший вариант по utility."""
        if not self.candidates:
            return None
        return max(self.candidates, key=lambda x: x[1].utility)
    
    def __repr__(self):
        return (
            f"DecisionSpace("
            f"candidates={len(self.candidates)}, "
            f"best_utility={self.best()[1].utility if self.best() else 0:.2f})"
        )

class DecisionHub:
    """Строит пространство решений (evaluate).
    
    Не выбирает, только считает скоры.
    Выбор остается IntentSelector.
    """
    
    def __init__(self, goal_scorer: GoalScorer):
        self.goal_scorer = goal_scorer
    
    def evaluate(
        self,
        npc: NPC,
        context: DecisionContext
    ) -> DecisionSpace:
        """Построить DecisionSpace на основе состояния NPC."""
        
        # Получить активные цели
        goals = npc.mind.motivational.goals.list_active()
        
        if not goals:
            # Если целей нет, возвращаем пустое пространство
            return DecisionSpace(candidates=[], context=context)
        
        # Оценить каждую цель
        scores = []
        for goal in goals:
            score = self.goal_scorer.score(goal, npc, context)
            scores.append((goal, score))
        
        return DecisionSpace(candidates=scores, context=context)
```

```python
"""
Intent Selector: выбирает из DecisionSpace.

R7: простой max по utility
R9+: может быть стохастичным, с учётом uncertainty
"""

from dataclasses import dataclass
from typing import Optional
from backend.app.models.npc.goals import Goal
from backend.app.services.decision.decision_hub import DecisionSpace
import random

@dataclass
class Intent:
    """Решение, которое примет NPC."""
    goal: Goal
    certainty: float  # 0.0-1.0, насколько уверены
    reasoning: str = ""

class IntentSelector:
    """Выбирает Intent из DecisionSpace."""
    
    def select(self, decision_space: DecisionSpace) -> Optional[Intent]:
        """Выбрать лучший Intent."""
        
        best = decision_space.best()
        if not best:
            return None
        
        goal, score = best
        
        # R7: детерминированный выбор (max по utility)
        return Intent(
            goal=goal,
            certainty=score.utility,
            reasoning=f"Best goal: {goal.type} (utility={score.utility:.2f})"
        )
    
    def select_stochastic(
        self,
        decision_space: DecisionSpace,
        temperature: float = 1.0
    ) -> Optional[Intent]:
        """Выбрать Intent вероятностно (для R9+).
        
        Args:
            temperature: как сильно смешивать варианты
                1.0 = давать всем равный шанс
                0.1 = сильно предпочитать лучший
        """
        
        if not decision_space.candidates:
            return None
        
        # Нормализовать utilities в вероятности
        utilities = [score.utility for _, score in decision_space.candidates]
        
        # Softmax с температурой
        max_u = max(utilities)
        exp_utils = [
            random.expovariate(1.0 / (max(u - max_u, 0.001) / temperature))
            for u in utilities
        ]
        total = sum(exp_utils)
        probs = [e / total for e in exp_utils]
        
        # Выбрать с учётом вероятностей
        chosen_idx = random.choices(
            range(len(decision_space.candidates)),
            weights=probs,
            k=1
        )[0]
        
        goal, score = decision_space.candidates[chosen_idx]
        
        return Intent(
            goal=goal,
            certainty=score.utility,
            reasoning=f"Stochastic choice: {goal.type} (prob={probs[chosen_idx]:.2f})"
        )
```

```python
class TraumaFilter:
    """Травма искажает восприятие угрозы.
    
    Если NPC пережил травму (например, нападение),
    последующие события воспринимаются как более опасные.
    """

        trauma_level = npc.mind.cognitive.memory.get_trauma_level()

            # Травматизированный NPC все воспринимает как более опасное

            perception.salience *= (1.0 + trauma_level * 0.3)
        
        return perception

class BeliefFilter:
    """Убеждения направляют внимание восприятия.
    
    Если NPC верит, что угрозы нет, он менее неуверен.
    Если верит, что угроза велика, он более неуверен.
    """
    
    def filter(self, perception: PerceptionEvent, npc: NPC) -> PerceptionEvent:
        
        danger_belief = npc.mind.epistemic.beliefs.get("danger")
        
        if danger_belief:
            # Убеждение в опасности снижает неопределённость
            if danger_belief.value > 0.7:
                perception.uncertainty *= 0.5
            # Убеждение что всё безопасно повышает неопределённость
            elif danger_belief.value < 0.3:
                perception.uncertainty *= 1.3
        
        return perception

# ============================================================================
```

```python
"""
Belief Transition Engine: вычисляет переходы убеждений.

Не мутирует BeliefState напрямую, а вычисляет новое состояние
и его записывает (через BeliefState.update()).
"""

from dataclasses import dataclass
from backend.app.models.npc.npc import NPC
from backend.app.models.npc.mind import BeliefFragment
from backend.app.services.perception.perception_filters import PerceptionEvent

class BeliefTransitionEngine:
    """Вычисляет новые убеждения на основе восприятия, памяти и старых убеждений."""
    
    def integrate(
        self,
        npc: NPC,
        perception: PerceptionEvent
    ) -> None:
        """Интегрировать новое восприятие в убеждения.
        
        Процесс:
        old_belief + perception + memory + trauma → new_belief
        """
        
        # Получить старое убеждение об опасности
        old_belief = npc.mind.epistemic.beliefs.get("danger")
        old_value = old_belief.value if old_belief else 0.5
        
        # Получить травму из памяти
        trauma = npc.mind.cognitive.memory.get_trauma_level()
        
        # Вычислить новое убеждение
        # Формула: Байесовское обновление с инерцией
        new_value = self._compute_belief(
            old_value=old_value,
            perception=perception.threat_level,
            trauma=trauma
        )
        
        # Записать новое убеждение
        npc.mind.epistemic.beliefs.update(
            "danger",
            BeliefFragment(
                value=new_value,
                confidence=self._compute_confidence(perception, trauma),
                source="perception_integration",
                timestamp=npc.current_tick  # нужна инъекция или через context
            )
        )
    
    def _compute_belief(
        self,
        old_value: float,
        perception: float,
        trauma: float
    ) -> float:
        """Байесовское обновление убеждения.
        
        Инерция: старое убеждение медленно меняется
        Травма: усиливает переход к высокому значению
        """
        
        # Инерция: 70% старое, 30% новое
        base_update = old_value * 0.7 + perception * 0.3
        
        # Травма усиливает тревожность
        trauma_boost = trauma * 0.2
        
        return min(1.0, base_update + trauma_boost)
    
    def _compute_confidence(
        self,
        perception: PerceptionEvent,
        trauma: float
    ) -> float:
        """Уверенность в убеждении (обратна неопределённости).
        
        Если восприятие неопределено, уверенность падает.
        Если травма, уверенность растет (даже если неправильная).
        """
        
        base_confidence = 1.0 - perception.uncertainty
        trauma_override = trauma * 0.3
        
        return min(1.0, base_confidence + trauma_override)
```

```python
                )
                
                # Пропустить через фильтры
                filtered_perception = self.perception_pipeline.process(
                    raw_perception, npc
                )
                
                # Интегрировать в убеждения
                self.belief_engine.integrate(npc, filtered_perception)
        
        # === РЕШЕНИЕ ===
        for npc in self.all_npcs:
            context = DecisionContext(
                observer=npc,
                current_tick=self.world_clock.tick
            )
            
            # Построить пространство решений
            decision_space = self.decision_hub.evaluate(npc, context)
            
            # Выбрать лучший вариант
            intent = self.intent_selector.select(decision_space)
            
            if intent:
                npc.current_intent = intent
        
        # === ДЕЙСТВИЕ и ОСТАЛЬНОЕ (не меняется) ===
        # ... (MovementEngine, Combat, и т.д.)
```
