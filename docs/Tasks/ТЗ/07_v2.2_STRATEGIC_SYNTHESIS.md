### ✅ Mutation Pipeline — 9.5/10

```
Event
  ↓ (RawEvent → Signal)

  ↓ (Evaluate relevance)
Evaluation
  ↓ (Propose change)

  ↓ (Validate against MIK)
```

## СЛОЙ 1: НАДСТРОЙКИ (опциональны, можно отключить)

### ❌→✅ TemporalDomain — правильная форма — 9/10

**v3.0 ошибка:** TemporalDomain как отдельная онтология

```python
# НЕПРАВИЛЬНО:
class TemporalDomain(Enum):
    REACTIVE
    SITUATIONAL
    ADAPTIVE
    STRUCTURAL
```

Это создает параллельную реальность.

**v2.1 ошибка:** TemporalDomain убит полностью

```python
# НЕПРАВИЛЬНО:
REACTIVE_UPDATE = 1
SITUATIONAL_UPDATE = 10
# Это просто расписание, теряет смысл
```

**Правильно: TemporalDomain как свойство состояния**

```python
class StateProperty:
    """Каждое состояние имеет временное поведение"""
    
    value: float
    
    # Когда это обновляется?
    update_frequency: int  # каждый тик, каждые 10, каждые 1000
    
    # Как быстро меняется?
    inertia: float        # 0.1 = легко меняется, 0.95 = упорно держится
    
    # Как восстанавливается?
    decay_rate: float     # В покое → базовое значение
    
    # Когда утрачивает актуальность?
    expiration_tick: int  # После этого = забыто

# Пример:
fear = StateProperty(
    value=0.8,
    update_frequency=1,        # Каждый тик может меняться
    inertia=0.2,               # Быстро меняется
    decay_rate=0.05,           # Быстро восстанавливается
    expiration_tick=current_tick + 50  # Забывается через 50 тиков
)

belief = StateProperty(
    value=0.6,
    update_frequency=1000,     # Очень редко меняется
    inertia=0.95,              # Упорно держится
    decay_rate=0.001,          # Медленно восстанавливается
    expiration_tick=current_tick + 100000  # Почти не забывается
)
```

**Преимущество:**
- TemporalDomain встроено в состояние, не отдельная онтология
- Можно отключить, система не рассыпется
- Естественно масштабируется новым состояниям

**Вероятность выжить через 2 года: 85%**

### ❌→✅ Ownership с источниками — 8.5/10

**v2.1 ошибка:** Монополия владельца

```python
# НЕПРАВИЛЬНО:
emotion_owner = AffectiveIntegrator
# Никто кроме AffectiveIntegrator не может менять emotion
```

Это создает бутылочное горлышко.

**Правильно: Владелец + разрешённые источники**

```python
class StateOwnership:
    """Владелец состояния + разрешённые источники"""
    
    state_name: str = "emotion"
    owner: str = "EmotionState"  # Только этот может Apply
    
    # Но несколько источников могут предлагать изменения
    allowed_sources: List[str] = [
        "PerceptionPayload",     # Восприятие может влиять
        "MemoryPayload",         # Память может влиять
        "PredictionPayload",     # Ожидание может влиять
        "TraumaImprint",         # Травма может влиять
    ]
    
    def propose_mutation(self, source: str, delta: float) -> bool:
        if source not in self.allowed_sources:
            return False  # Отказать
        
        # Owner (EmotionState) примет решение о Apply
        return self.owner.consider_mutation(source, delta)
```

**Преимущество:**
- Владелец остаётся одним
- Но система не блокируется
- Много источников могут влиять на одно состояние

**Вероятность выжить через 2 года: 85%**

### ❌→✅ Expectation Loop — правильная форма — 8.5/10

**v3.0 ошибка:** Expectation Loop как отдельная система

```python
# НЕПРАВИЛЬНО:
prediction_model.predict()
affect_from_surprise()
# Создает параллельную реальность
```

**v2.1 ошибка:** Expectation Loop убит

```python
# НЕПРАВИЛЬНО:
# Никакого ожидания, просто реактивность
```

**Правильно: Expectation как модификатор восприятия**

```python
class ExpectationModifier:
    """Ожидание не создаёт эмоцию, меняет восприятие"""
    
    def apply_expectation_lens(self, perception: PerceptionEvent) -> PerceptionEvent:
        """
        Ожидание меняет, как ты воспринимаешь события
        """
        
        # Если я жду угрозу:
        if self.expects_threat:
            # Нейтральный жест → интерпретирую как агрессию
            perception.salience *= 1.5
            perception.semantic_seed = self._reinterpret_as_threat(perception.semantic_seed)
        
        # Если я жду друга:
        elif self.expects_friend:
            # Вещи интерпретирую благожелательнее
            perception.salience *= 0.7
        
        return perception
    
    def compute_prediction_error(self, perception: PerceptionEvent) -> float:
        """
        Ошибка = surprise
        Surprise → AttentionWeight (не эмоция!)
        """
        error = abs(self.prediction_value - perception.actual_value)
        return error
    
    def affect_from_surprise(self, error: float) -> EmotionPayload:
        """
        Большая ошибка → ATTENTION SPIKE
        Не создаю эмоцию, только усиливаю внимание
        """
        if error > 0.7:
            return EmotionPayload(
                emotion="alert",  # Не fear, а alert
                intensity=error,
                source="prediction_error"
            )
        return None
```

**Преимущество:**
- Expectation не создает параллельную реальность
- Меняет только восприятие (линзу)
- Зависит от Perception, не конкурирует с ней

**Вероятность выжить через 2 года: 80%**

### ❌ PhaseSpace — нужно правильнее — 6/10

**Kami выявил:** PhaseSpace скрывает непрозрачность.

**Решение:** Использовать, но с attractor points (не свободная геометрия)

```python
class PersonalityPhaseSpace:
    """Архетипы как аттрактеры в пространстве"""
    
    # Оси остаются, но:
    fear_aggression: float      # -1 to +1
    submission_dominance: float # -1 to +1
    isolation_social: float     # -1 to +1
    
    # Но архетипы = ATTRACTOR POINTS (не свободные точки)
    ATTRACTOR_POINTS = {
        "BROKEN": (-0.9, -0.9, +0.1),
        "COWARD": (-0.8, -0.6, -0.2),
        "LEADER": (+0.7, +0.8, +0.6),
    }
    
    def get_dominant_archetype(self) -> str:
        """Какой аттрактор ближайший?"""
        current = (self.fear_aggression, self.submission_dominance, self.isolation_social)
        
        nearest = min(
            self.ATTRACTOR_POINTS.items(),
            key=lambda a: self._euclidean_distance(current, a[1])
        )
        return nearest[0]
    
    def shift_toward_archetype(self, target: str, magnitude: float):
        """Плавный сдвиг, но в сторону аттрактора"""
        target_point = self.ATTRACTOR_POINTS[target]
        
        # Не свободный сдвиг, а управляемое движение к аттрактору
        for i, (current, target_val) in enumerate(
            zip([self.fear_aggression, self.submission_dominance, self.isolation_social],
                target_point)
        ):
            new_val = current + (target_val - current) * magnitude
            # Клэмпинг, не выход за пределы [-1, +1]
            setattr(self, [...], max(-1.0, min(1.0, new_val)))
```

**Преимущество:**
- Архетипы — это аттрактеры, не произвольные точки
- Система имеет "гравитационные лунки"
- Поведение предсказуемо

**Вероятность выжить через 2 года: 65%**

```python
class ComplexityScore:
    """Мониторим, не блокируем"""
    
    direct_deps: int = 5        # Сколько прямых зависимостей
    transitive_depth: int = 3   # Насколько глубокие цепи
    cycle_count: int = 2        # Есть ли циклы?
    
    def compute(self):
        return (
            0.5 * (direct_deps / 10) +      # 50% от прямых
            0.3 * (transitive_depth / 5) +  # 30% от глубины
            0.2 * min(cycle_count, 5)       # 20% от циклов
        )
    
    def is_healthy(self) -> bool:
        return self.compute() < 0.6  # Порог, не лимит

if score > 0.6:
```
