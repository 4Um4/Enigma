### Баг 1: `randint(2, 20)` — неправильный бросок d20

**Файл:** `backend/app/agents/rules_agent.py` строки 231-234

```python
# СЕЙЧАС (сломано):
result = self.resolve(
    random.randint(2, 20) if not adv and not dis
    else max(random.randint(2, 20), random.randint(2, 20)) if adv
    else min(random.randint(2, 20), random.randint(2, 20)),
    dc
) if roll_needed else "автоматический успех",
```

**Что не так:** `randint(2, 20)` исключает 1 (критический промах) и не включает 20 как особое значение. D&D 5e использует 1d20 = `randint(1, 20)`.

**Как чинить:**
```python
# ЗАМЕНИТЬ ВСЕ randint(2, 20) на randint(1, 20):
result = self.resolve(
    random.randint(1, 20) if not adv and not dis
    else max(random.randint(1, 20), random.randint(1, 20)) if adv
    else min(random.randint(1, 20), random.randint(1, 20)),
    dc
) if roll_needed else "автоматический успех",
```

### Баг 2: `LLMCompressorClient` обходит Provider-слой

**Файл:** `backend/app/services/input/llm_compressor_client.py` строки 21-41

```python
# СЕЙЧАС (сломано):
class LlamaCppCompressorClient:
    def __init__(self, base_url: str = "http://127.0.0.1:8080"):  # ← захардкожено
        ...
    async def compress_intent(self, ...):
        async with httpx.AsyncClient(timeout=2.0) as client:  # ← прямой HTTP, минуя ModelRouter
            response = await client.post(f"{self.base_url}/completion", json=payload)
```

**Что не так:**
- Жёстко заданный localhost:8080 — игнорирует `settings.llama_cpp_server_url`
- Игнорирует `provider_type` — если настроен OpenAI/Anthropic, всё равно стучится на localhost
- Обходит VRAM-семафор в ModelRouter
- Таймаут 2 сек — слишком мало для 7B модели
- `response_format: json_object` — llama.cpp `/completion` это НЕ поддерживает

**Как чинить:**
```python
# ЗАМЕНИТЬ: внедрить ModelRouter как зависимость
class LLMCompressorClient:
    def __init__(self, model_router: ModelRouter):
        self._router = model_router

    async def compress_intent(self, prompt: str, context: str) -> dict:
        response = await self._router.request_for_agent(
            agent_name="intent_compressor",
            prompt=prompt,
            system_prompt="Compress the following player input into a structured intent...",
            max_tokens=150,
        )
        return self._parse_json_response(response)
```

### Баг 6: `stream_complete()` не переопределён — фейковый стриминг

**Файл:** `backend/app/services/llm/provider.py` строки 126-149 + `anthropic_provider.py`, `openai_provider.py`, `ollama_provider.py`, `vllm_provider.py`

```python
# Базовый класс вызывает self.complete() (НЕ стриминг!), потом отдаёт всё разом:
async def stream_complete(self, prompt, ..., callback):
    result = await self.complete(prompt, ...)  # ← весь ответ сразу
    callback(result)                           # ← "стриминг" одним куском
```

**Как чинить:** В каждом из 4 провайдеров переопределить:
```python
# В anthropic_provider.py, openai_provider.py, ollama_provider.py, vllm_provider.py:
async def stream_complete(self, prompt, ..., callback):
    async for token in self.stream_tokens(prompt, ...):
        callback(token)
```

### Баг 7: `world_sim_agent.tick()` с `location="unknown"`

**Файл:** `backend/app/agents/world_sim_agent.py` строки 129-143

```python
# СЕЙЧАС (сломано):
async def tick(self):
    result = await self.run(location="unknown", actions=[], current_events=[])
    # → каждый мировой тик = контекстно-свободный ответ
```

**Как чинить:**
```python
# ЗАМЕНИТЬ: принимать реальные данные
async def tick(self, location: str, recent_actions: list, current_events: list):
    result = await self.run(
        location=location,
        actions=recent_actions,
        current_events=current_events,
    )
    return result
```
