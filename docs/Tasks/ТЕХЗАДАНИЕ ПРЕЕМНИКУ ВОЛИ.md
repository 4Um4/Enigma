## 1. КОРНЕВЫЕ ПРИЧИНЫ (3 БАГА)

### БАГ Z: Zombie Traversals (ФИКС ИСПРАВЛЕН ИНЛАЙН)

**Симптом:** traversals со статусом "COMPLETED" остаются в `active_traversals` навсегда.
**Причина:** Строка 1114: `# STL: Удаление запрещено. Меняем статус на COMPLETED.`
**Фикс:** Добавлен zombie cleanup после цикла обработки traversals.
**Результат:** traversals теперь очищаются. comparisons выросли с 7 до 12 за 100 тиков (+71%).

**Текущий код (УЖЕ В ФАЙЛЕ):**
```python
# Очистка COMPLETED traversals (zombie cleanup)
_zombie_ids = [nid for nid, t in traversals.items() if t.get("status") == "COMPLETED"]
for _zid in _zombie_ids:
    del traversals[_zid]
```

### БАГ N: NODE_NOT_FOUND (НЕ ИСПРАВЛЕН — PRIMARY BOTTLENECK)

**Симптом:** `spatial_changes=0` каждый тик, comparisons = 0.02/tick вместо 0.99/tick (46x разница с S85).
**Причина:** `blacksmith_orm` хочет идти в `workshop_area`, но в графе `market_square` существует только `room_0` (изолированная компонента).
**Causal chain:**
```text
life_intents=3 → accepted=1 (blacksmith_orm) → NODE_NOT_FOUND → spatial_changes=0 → shadow pipeline starving
```
**Требуется:** Археология JSON-данных — откуда берётся `workshop_area` и почему его нет в графе.

### БАГ C: Topological Drift Regression (НЕ ИССЛЕДОВАН)

**Симптом:** C=3.26% (7 случаев за 215 comparisons). В S85 было C=0.00%.
**Причина:** Неизвестна. EquivalenceValidator логирует через `logger.warning` (подавлен), добавлен `print()`.
**Требуется:** Собрать C-drift с деталями (какие NPC, какие узлы).
