======================================================================
ЧАСТЬ IX.5 — CONFIDENCE CALIBRATION
======================================================================

Вероятность запрещено выводить из интуиции.

Допустимые источники:

+ наблюдаемый лог
+ assertion
+ traceback
+ runtime state
+ process state
+ contract mismatch
+ CDS signal

Запрещено:

"is_available=False"

↓

"сервер не запущен (90%)"

Если отсутствуют прямые наблюдения:

MAX_PROBABILITY:

60%

Если отсутствуют runtime доказательства:

MAX_PROBABILITY:

40%

Вероятность >80 допустима только при:

□ воспроизводимом сценарии

или

□ прямом логе

или

□ найденном писателе состояния

======================================================================
ЧАСТЬ X — ROOT CAUSE VALIDATION
======================================================================

Посчитать:

ROOT_CAUSE_CONFIDENCE:

0–40:

Диагностика только

Разрешено:

- логирование
- assertions
- trace

Запрещено:

- фикс
- ADR
- рефакторинг

40–80:

Разрешено:

- локальная проверка
- временный trace

Запрещено:

- изменение ownership
- изменение pipeline

80–100:

Разрешён фикс
