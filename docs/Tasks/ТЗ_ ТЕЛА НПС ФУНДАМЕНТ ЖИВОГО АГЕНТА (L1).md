# ТЗ: ТЕЛА НПС — ФУНДАМЕНТ ЖИВОГО АГЕНТА (L1)

**Проект:** ENIGMA Engine  
**Ветка:** V.0.5.5.0_L1_AGENT_CORE  
**Онтология:** Агент — это не набор плоских статов (`social_stats.trust = 50`), а инерционная физико-когнитивная система. Личность сопротивляется изменениям. Тело адаптируется к травмам. Воля конфликтует со страхом.  
**Цель:** Внедрить `LivingNPC` как ядро состояния агента, заменив плоские словари. Без этого слоя Невозможно строить восприятие (L0) и поведение (L2).

---

## 1. АРХИТЕКТУРНЫЙ СДВИГ: ОТ СТАТОВ К ИНЕРЦИИ

**Запрет:** В системе больше нет прямой мутации вида `npc.fear += 0.2`. Любое внешнее воздействие проходит через фильтр инерции личности. Трусливый NPC реагирует на угрозу быстрее и сильнее, чем смелый, и медленнее восстанавливается.

**Базовая формула инерции (L1 Core Formula):**
```python
new_value = (old_value * INERTIA_WEIGHT) + (delta * (1 - INERTIA_WEIGHT))
```
Где `INERTIA_WEIGHT` берется из `IdentityCore` (базовая ригидность личности, обычно `0.9`). Это гарантирует, что разовое событие не ломает психику мгновенно, но хроническое давление накапливается.

## 2. КЛЮЧЕВЫЕ DTO (Data Transfer Objects)

### 2.1. IdentityCore (Неизменяемый фундамент)
Генерируется один раз при рождении/инициализации NPC. Определяет базовую форму "сосуда" психики.

```python
from dataclasses import dataclass, field
from typing import Dict

@dataclass(frozen=True)
class IdentityCore:
    """Фундаментальные черты личности. Крайне трудно поддаются изменению."""
    
    # Базовые предрасположенности (0.0 - 1.0)
    base_aggression: float = 0.3       # Склонность к насилию
    base_trust: float = 0.5            # Базовое доверие к незнакомцам
    base_fear: float = 0.4             # Базовый уровень тревожности
    base_curiosity: float = 0.3        # Склонность к исследованию
    
    # Социальная конфигурация
    social_drive: float = 0.5          # Потребность в стае/общении
    dominance_bias: float = 0.2        # Склонность подчинять (0.0 = раб, 1.0 = тиран)
    compliance_bias: float = 0.6       # Склонность подчиняться правилам
    
    # Мета-параметры
    rigidity: float = 0.9              # Инерция личности (0.0 = истерик, 1.0 = камень)
    recovery_rate: float = 0.1         # Скорость возврата к базовым значениям в покое
```

### 2.2. DriveSystem (Конфликтующие потребности)
Текущее мотивационное напряжение. Заменяет флаги `is_hungry`, `wants_sleep`. Драйвы конкурируют друг с другом за право определить действие.

```python
@dataclass
class DriveSystem:
    """Текущие мотивационные векторы агента. Изменяются средой и физиологией."""
    
    # Первичные (Физиология)
    survival: float = 0.1      # Угроза жизни (0.0 = безопасно, 1.0 = паника)
    satiety: float = 0.2       # Голод (0.0 = сыт, 1.0 = умирает от голода)
    rest: float = 0.1          # Усталость (0.0 = бодр, 1.0 = валится с ног)
    
    # Вторичные (Социум и Воля)
    social: float = 0.2        # Потребность в контакте/статусе
    autonomy: float = 0.1      # Потребность в свободе действий (растет при давлении)
    
    # Производная
    stress: float = 0.0        # Общий уровень стресса (вычисляется из конфликта драйвов)
    
    def get_dominant_drive(self) -> str:
        """Возвращает имя самого напряженного драйва."""
        ...
```

### 2.3. BodySchema (Динамическое тело)
Расширение концепта NPC. Тело — это не просто `speed=2.0`, это фильтр реальности и генератор кинематики. Тело меняется под давлением среды (морфологический дрейф) и влияет на то, как NPC видит мир.

```python
@dataclass
class BodySchema:
    """Динамическое физическое и когнитивное состояние тела агента."""
    
    # Физические лимиты
    max_velocity: float = 4.0          # Максимальная скорость бега
    vault_capability: float = 0.8      # Способность перепрыгивать (0.0-1.0)
    climb_capability: float = 0.8      # Способность лазить (0.0-1.0)
    concealment_volume: float = 0.8    # Насколько компактно может спрятаться (0.0-1.0)
    
    # Когнитивные модификаторы тела (Травмы меняют восприятие)
    tunnel_vision_factor: float = 0.0  # 0.0 = норма, 1.0 = полная паника, видит только угрозу
    pain_threshold: float = 0.5        # Боль выше этого порога глушит социальные драйвы
    
    # Ресурсы
    mana_channel: float = 0.0          # -1.0 (тьма) до 1.0 (свет)
    mana_capacity: float = 0.0
```

Числа (`fear = 0.8`) не говорят игроку и LLM ничего. Архетип — это ярлык фазового состояния, который меняет лексику, микро-выражения и стиль принятия решений.

## 3. АГРЕГАТОР: LivingNPC

Единый контейнер состояния, заменяющий плоский `NPCState` (или расширяющий его).

```python
@dataclass
class LivingNPC:
    """Агрегат состояния живого агента. Не имеет логики, только данные и инерция."""
    
    npc_id: str
    
    # Ядро (постоянно)
    core: IdentityCore = field(default_factory=IdentityCore)
    
    # Состояния (изменяются с инерцией)
    drives: DriveSystem = field(default_factory=DriveSystem)
    body: BodySchema = field(default_factory=BodySchema)
    archetype: ArchetypeLabel = field(default_factory=ArchetypeLabel)
    
    # Отношения (Заглушка для Спринта 4, пока только float-вектор)
    # Интерфейс: player_trust, player_fear
    relationship_cache: Dict[str, float] = field(default_factory=lambda: {"player_trust": 0.5, "player_fear": 0.0})
    
    def apply_delta(self, domain: str, attribute: str, delta: float):
        """
        Единая точка входа для изменения состояния.
        Применяет инерцию core.rigidity.
        """
        current_value = getattr(getattr(self, domain), attribute)
        weight = self.core.rigidity
        new_value = (current_value * weight) + (delta * (1 - weight))
        
        # Клэмпинг в [0.0, 1.0]
        setattr(getattr(self, domain), attribute, max(0.0, min(1.0, new_value)))
```

## 4. ЛОГИКА АРХЕТИПОВ (Алгоритм перехода)

Архетип вычисляется на стыке `IdentityCore` и `DriveSystem` в конце каждого тика.

```python
# Внутри ArchetypeLabel.update()
def update(self, core: IdentityCore, drives: DriveSystem):
    # 1. Оценка оси Насилия
    if drives.survival > 0.8 and core.base_aggression < 0.3:
        self.violence = ViolenceArchetype.VICTIM
    elif drives.survival > 0.5 and core.base_aggression > 0.6:
        self.violence = ViolenceArchetype.AVENGER
    elif drives.stress < 0.3:
        self.violence = ViolenceArchetype.SURVIVOR # Базовое состояние
        
    # 2. Оценка Социальной оси
    if drives.social < 0.2 and drives.stress > 0.7:
        self.social = SocialArchetype.BROKEN
    elif drives.survival > 0.6 and core.base_trust < 0.3:
        self.social = SocialArchetype.COWARD
    elif drives.stress < 0.3 and core.dominance_bias > 0.7:
        self.social = SocialArchetype.LEADER
    # ... остальные переходы
```

## 5. СВЯЗЬ ТЕЛА И ПСИХИКИ (Body-Mind Interface)

Тело влияет на драйвы, а драйвы меняют тело. Это замкнутый контур внутри агента.

1. **Стресс -> Тело:** Если `DriveSystem.stress > 0.7`, `BodySchema.tunnel_vision_factor` растет. NPC перестает замечать аффордансы укрытия по бокам (в будущих спринтах).
2. **Боль -> Психика:** Если `BodySchema.pain_threshold` превышен (получен урон), `DriveSystem.survival` скачет до `1.0`, а `DriveSystem.social` падает до `0.0`. NPC забывает о приличиях.
3. **Усталость -> Тело:** `DriveSystem.rest > 0.8` снижает `BodySchema.max_velocity` на 50%.

## 6. ИНТЕГРАЦИЯ В КОД (Migration Path)

1. Найти текущий класс `NPCState` (или аналог) в проекте.
2. Добавить `LivingNPC` как вложенный объект `living: LivingNPC`.
3. Найти места, где прямо мутируются статы (например, `npc.fear += 0.1`).
4. Заменить их на `npc.living.apply_delta("drives", "survival", 0.1)`.
5. Найти `TickOrchestrator`. Добавить вызов `npc.living.archetype.update(npc.living.core, npc.living.drives)` в фазу разрешения состояния (перед принятием решений).

## 7. КРИТЕРИЙ ПРИЕМКИ (ПЕСОЧНИЦА)

Создать тест `tests/sandbox/micro/test_living_npc_inertia.py`.

**Сценарий:**
1. Инициализировать `LivingNPC` с `base_fear=0.3`, `rigidity=0.9`.
2. Нанести удар: `npc.apply_delta("drives", "survival", 0.5)`.
3. **Проверка 1:** `npc.drives.survival` должен стать `0.3 * 0.9 + 0.5 * 0.1 = 0.32` (а не 0.8). Инерция работает.
4. Нанести еще 5 ударов: `apply_delta` вызывается 5 раз подряд.
5. **Проверка 2:** `npc.drives.survival` превысил `0.7`. Архетип сменился на `COWARD` или `VICTIM`.
6. **Проверка 3:** `npc.body.tunnel_vision_factor` начал расти из-за высокого стресса.
