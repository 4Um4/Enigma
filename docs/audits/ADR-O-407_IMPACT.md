# ADR-O-407 Impact Audit
> Этот файл — детальный аудит ОДНОГО ADR. Единый атлас всех ADR: `docs/ADR (Architecture Decision Records).md`
> Статус: APPROVED-BY-MASTER, реализация — отдельная сессия. Этот audit фиксирует КОНТРАКТ до кода (PRE-FLIGHT-форма).

## Changed Domains
- **Время / execution model игрока** — гейт продвижения мирового времени привязан к player-turn commitment, не к LLM-вызову.
- **GameLoop (уровень оркестратора)** — флаг `player_turn_in_flight` (по образцу `workbench_paused`); ядро (TickOrchestrator) не меняется.

## Онтологическая сверка (почему это не нарушение существующих законов)
| Закон | Вердикт | Обоснование |
|---|---|---|
| ADR-O-344 (WorldTick Temporal Ownership) | не затронут | TickOrchestrator остаётся единственным владельцем `game_time_seconds`; гейт решает только «вызывать ли execute()» |
| ADR-TZ08-1 (ядро не знает player) | не затронут | флаг живёт в game_loop; InterventionEvent-контракт неизменен |
| ADR-002 («время не останавливается») | переформулирован, не нарушен | время не останавливается ВНУТРИ исполняемых тиков; неисполненный тик не существует (семантика F12/workbench-паузы) |
| ADR-O-364 (Per-Task Timeout) | переиспользуется | abort → честная ошибка хода (ADR-113) → пауза снимается; вечный фриз невозможен |
| INV-REPLAY-DETERMINISM | цел | окно паузы не порождает событий: в записи отсутствуют тики — реплей воспроизводит последовательность как есть |
| ADR-O-406 (ControlSource) | семантический мост | COMBAT_CONTROLLER зарезервирован: будущий боевой controller — второй держатель commitment |

## Downstream Consumers
| Потребитель | Эффект |
|---|---|
| Фаза 0.5 (decay/расписания) | не исполняется в окне хода → суточные циклы не проматываются во время генерации (корень П.4: 20+ игровых минут за реплику) |
| NPC-диалоговая материализация (ADR-O-313) | НЕ паузится: NPC думают в живом мире; backpressure (ADR-O-363/364) уже обвязан |
| TaskScheduler | работает как есть; player-turn не кладёт задачи в очередь в окне паузы |
| Фронтенд | индикатор «мир ждёт вердикта хода» (future; не входит в минимальную реализацию) |
| Реплей/DriftLab | пустые окна в записи — безразлично |

## Runtime Impact
- RAM: ~0 (один булев флаг в game_loop)
- Tick latency: 0 (гейт — один if вне тика)
- Геймплей: устранение «мир съедает полдня за реплику» (П.4 ТЗ проекционного слоя)

## Scope (минимальная реализация, будущая сессия)
1. Флаг `player_turn_in_flight` в game_loop: set → dispatch хода; clear → Artifact / FAILED / timeout-abort;
2. `idle_tick` при флаге не вызывает `execute()`;
3. Никаких новых таймеров (переиспользование ADR-O-364);
4. Инвариант **INV-PLAYER-TURN-TIME-GATE**: между dispatch и resolve хода ни один idle-тик не исполняется; `game_time_seconds` не растёт (кандидат в IPT).

## Sandbox Tests (план)
- Runtime: прогон «фраза игрока → N секунд генерации → game_time_seconds не изменился» (до: +20 мин);
- IPT-кандидат: INV-PLAYER-TURN-TIME-GATE (после реализации);
- Регресс: NPC-NPC диалоги продолжают материализоваться в живом времени.

## Rollback
Удалить флаг + гейт-if в idle_tick. Поведение возвращается к «мир тикает всегда» (ADR-002 как есть).

## Связи
- Рождён из П.4 исходного ТЗ (три бага проекционного слоя, S292) — вердикт Мастера: вариант (а), переформулированный в commitment-семантику (не global LLM-pause — будущий мультиплеер 500 NPC / 10000 players).
- Соседний резерв: ADR-O-406 ControlSource.COMBAT_CONTROLLER.
