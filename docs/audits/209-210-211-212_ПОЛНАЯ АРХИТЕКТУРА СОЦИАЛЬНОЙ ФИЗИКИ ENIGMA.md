## 1. СЛОЙ ИДЕНТИЧНОСТИ (ADR-O-209)

**Trait = устойчивое искажение решений, а не тег.**

*   Trait не добавляет вес к скору.
*   Trait меняет **доступность доменов решений** (Viability Gate).
*   Trait — это **шрам**, который деформирует геометрию выбора.

**Модель:** CSV (CausalStateVector) — точка фиксации фазы личности. Меняется только через Commit Event (Φ_stable).

---

## 2. СЛОЙ ВОСПРИЯТИЯ (ADR-O-210)

**CFL = чистая функция свёртки, а не объект.**

*   Emission → Sampling → Forget.
*   Стены блокируют социальное давление (LOS check).
*   Saturation Cap предотвращает инфляцию толпы.

---

## 3. СЛОЙ ПАМЯТИ (ЕДИНСТВЕННАЯ социальная истина)

**VillageMemoryField = функция аппроксимации поведения группы во времени.**

*   Живёт в SceneState.
*   Обновляется через SocialMemoryUpdater (отдельный сервис).
*   Ingest = event-driven, Decay/Diffusion = tick-driven.
*   НЕ агрегация страхов NPC. Агрегация событий × свидетели × последствия.
*   ЗАПРЕЩЕНО выделять Narrative Gravity как отдельный слой данных (риск Double Truth). Нарратив — производный эффект от VillageMemoryField + time + repetition.

**VillageMemoryField = социальная интерпретация реальности.**

*   Живёт в SceneState.
*   Обновляется через SocialMemoryUpdater (отдельный сервис).
*   Ingest = event-driven, Decay/Diffusion = tick-driven.
*   НЕ агрегация страхов NPC. Агрегация событий × свидетели × последствия.

**Формула консенсуса:**
```
social_weight = intensity × log(1 + witnesses) × victim_multiplier × recency_decay
consensus_risk = Σ(social_weight) / normalization
```

**Agent Risk Profile (Мифологизация):**
```
myth_level увеличивается только через:
- multi-location events
- witness propagation
- contradiction between reports
НЕ через количество убийств.
```

## 4. СЛОЙ ИНСТИТУЦИЙ (НОВЫЙ)

**InstitutionLayer = медленные структурные коэффициенты мира.**

*   НЕ выбирается NPC. Рождается как агрегат давления памяти.
*   Влияет через Decision Bias Layer, НЕ через прямое управление.
*   ЗАПРЕЩЕНА мгновенная реакция на события. Общество — система задержек.

```python
@dataclass
class InstitutionalInertia:
    resistance_to_change: float   # 0.0–1.0 (0 = ЗАПРЕЩЕНО; 1 = абсолютный консерватизм)
    adaptation_rate: float        # скорость реакции системы на давление (0.01–0.1)
    memory_half_life: float       # время полураспада реакции

@dataclass
class VillageInstitutionLayer:
    patrol_density: float          # 0.0 = нет патрулей, 1.0 = вооружённые группы
    trade_restrictions: Dict[str, float]  # agent_id → risk_modifier
    curfew_level: float            # 0.0 = свободно, 1.0 = комендантский час
    group_formation_bias: float    # склонность к коллективным действиям
    inertia: InstitutionalInertia  # Анти-эскалация. target = f(consensus), actual += (target - actual) * α
```


**Механика перехода:**
```text
consensus_risk > threshold_1 → patrol_density ↑
repeat_violence_in_location → curfew emerges
agent_profile.myth_level high → targeted response units
```

## 5. ПОЛНЫЙ КАУЗАЛЬНЫЙ КОНВЕЙЕР

```text
[Событие] Игрок убил NPC
     ↓
[SocialMemoryUpdater.ingest] 
     ↓ social_weight = 0.9 × log(4) × 1.0 = 1.25
     ↓
[VillageMemoryField] consensus_risk растёт
     ↓
[AgentRiskProfile] myth_level растёт при multi-location + witnesses
     ↓
[InstitutionLayer] patrol_density ЦЕЛЬ растёт. actual += (target - actual) * inertia.adaptation_rate
     ↓
[Decision Bias] effective_risk = base_risk * 0.6 + consensus_risk * 0.4
```

## 6. ИНЖЕНЕРНЫЕ ПРИНЦИПЫ (Анти-Мифологизация)

1. **4 слоя — достаточно.** Физика (LifeEngine), Психика (RiskField), Общество (VillageMemoryField), Политика (InstitutionLayer). Никаких дополнительных "слоёв реальности".
2. **Нарратив — производный эффект.** Запрещено выделять Narrative Gravity как отдельный слой данных (риск Double Truth и расхождения между историей и интерпретацией). Он формируется через exposure × repetition × resolution_delay.
3. **Мир должен быть медленным.** Память → медленная. Институты → очень медленные. Слухи → средние. Личный страх → быстрый. Ничего не должно быть мгновенным.
4. **Игрок — один из источников.** Игрок не центр мира. Он источник событий в статистике мира. Иногда важный, иногда незаметный.
