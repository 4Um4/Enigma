# ADR-O-422 Impact Audit
> Этот файл — детальный аудит ОДНОГО ADR. Единый атлас всех ADR: `docs/ADR (Architecture Decision Records).md`

ADR-O-422 [STANDARD] **IMPACT** (S336; CCH-2.5 Chronicle Consistency — сверка авторского плетения)

## Changed Domains
- authoring: новый сервис сверки (вне тик-контура, нулевое runtime-влияние)
- домен chronicle: аддитивно game_start_age / event_groups (optional, schema_version=1 сохранён — обратная совместимость чтения старых файлов)
- API: +POST check-эндпоинт (routes_chronicle)

## Downstream Consumers
- CCH-3: UI-карточки конфликтов/склеек читают ConsistencyReport
- CCH-4: сеялка получает согласованный канон (карточки разрешены автором до seed)
- CCH-6: калибровка маркеров/ролей на корпусе биографий

## Runtime Impact
- Ноль для тик-пайплайна; check — по требованию автора/редактора

## Sandbox Tests
- tests/micro/test_chronicle_consistency.py — WARA-расширение, три уровня сверки
- Приёмочный гейт: авторский корпус «Люся+Торнин» (Мастер, S336) — система сама выдаёт: имена-опечатки (Лом/Рома≠Орм), окно 12–14, две интерпретации кружки (склейка+разные Knowledge), «не помню откуда знаю» (легальность), возрастная согласованность 9↔40 (start 14↔45), предложения новых секретов

## Rollback
- Удалить consistency_service + check-эндпоинт; домен-поля optional — старые читатели не ломаются

## Решения владельца (S336)
- Вытеснение фактов: канон-файл = актуальный снимок; история — git + append-only author_text черновика; запущенные кампании не обновляются (seed-отлив, ADR-O-420)
- Склейка: место+время+роли; зеркальная анонимность совместима; финал — карточка автору

## Реализация (S336)
- consistency_service: intra (_window с правой границей game_start_age — «сейчас» легальный якорь; unified с cross-семантикой), cross (delta = разность game_start_age; матчатся ВСЕ участники с self-ref-фильтром — объект=владелец своей хроники не даёт роли), canon (alias→archetype-роли, CONTRADICTION на несуществующих NPC, CANON_SYNC на known_by-расхождение, QUESTION на неразрешимые имена)
- Деградации нормализатора (калибровка пробы): confidence None → 0.5+needs_confirmation; мусорные опции вопросов выбрасываются поимённо (LEAVE_WHITE_SPOT всегда добавлен); confidence вне [0,1] — по-прежнему fail-loud (нарушение схемы ≠ забытая опция)
- Приёмка: chronicle_weave_probe GREEN 7/0 (живой Q4_K_M, 33/33 авторских фрагментов Мастера, 73 записи, drafts сохранены); корпус вскрывал дефекты 3 итерациями (окна, деградации, матчинг) — калибровочный контур работает
- Граница v1: структурный матчинг даёт много кандидатов у со-локальных хроник — дедуп/приоритизация = UI CCH-3 (карточки), не дефект
- Хвосты CCH-3: местоименные хинты-фильтр, self-ref-INFO-повышение, канон-пополнения (Серебряная Луна/Серебряный Волк), Лом/Рома-резолюции т9-опечаток
