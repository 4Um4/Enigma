## Дорожная карта: Контракты > Пути

### 🔴 КРИТИЧЕСКИЙ — Нарушение Устава §2.1 / §7.8

**`WorldTickResult.events: List[dict]`** — события NPC = сироты, нетипизированные

| Проблема | Доказательство |
|---|---|
| `WorldTickEngine` возвращает `List[dict]` вместо `List[EventDTO]` | `world_tick_engine.py:49` |
| Ни один потребитель не может типизировать обработку | Устав §7.8 прямо запрещает |

**Решение:** `WorldTickResult.events: List[EventDTO]`, конвертация внутри engine.

---

### 🔴 КРИТИЧЕСКИЙ — Dict-мутации вместо контрактов

**`psyche_engine.py` — принимает и возвращает `Dict`**

| Проблема | Доказательство |
|---|---|
| `apply_stress(npc: Dict, amount: int) -> Dict` | Строка 15 |
| `resolve_coercion(npc: Dict, ...) -> Dict` | Строка 57 |
| `check_loyalty_break(npc: Dict) -> bool` | Строка 116 |
| Нет типизации, нет атомарности, нет защиты от полумутаций | — |

**Решение:** `psyche_engine` должен принимать `NPCState` и возвращать `StateDeltas` — как `DecisionHub`. `StateApplicator` применяет.

---

### 🟡 ВЫСОКИЙ — Дублирование контракта мутаций

**`StateDeltas` существует только в `decision_hub.py`** — каждый мутатор создаёт свою структуру

| Источник мутации | Что возвращает | Тип |
|---|---|---|
| `DecisionHub` | `DecisionResult.deltas: StateDeltas` | ✅ Типизировано |
| `StateApplicator.apply_physical()` | мутирует `NPCState` напрямую | ❌ Нет контракта |
| `psyche_engine.apply_stress()` | `Dict` | ❌ Нет контракта |
| `WorldTickEngine` | `List[dict]` | ❌ Нет контракта |
| `SocialEngine.propagate()` | мутирует `Dict` | ❌ Нет контракта |

**Решение:** Единый `StateDeltas` в `app/models/state_delta.py`. Все мутаторы возвращают его. `StateApplicator` — единственный потребитель.

---

### 🟡 ВЫСОКИЙ — Отсутствие `TemporalEngine` (Время · Decay)

| Проблема | Где сейчас |
|---|---|
| Decay логика разбросана | `StateApplicator._apply_trait_decay()`, `working_memory_tick.py`, `calendar.py` |
| Нет единой точки: «сколько тиков прошло, что протухло» | Каждый модуль считает сам |
| Stress recovery без учёта времени | `psyche_engine.recover_stress(ticks_safe)` — параметр, не запрос к движку |

**Решение:** `services/temporal/temporal_engine.py` — знает текущий тик, считает decay для всех подсистем.

---

### 🟡 ВЫСОКИЙ — `interpretation_engine` разделён

| Диаграмма | Текущее | Проблема |
|---|---|---|
| `interpretation_engine.py` (Угроза/Флирт?) | `cognitive_distortion.py` + `npc_cognition.py` + `threat_assessor.py` | Три файла делают одну работу: «что это событие значит для NPC» |

**Решение:** Консолидировать в один `interpretation_engine.py` с чётким контрактом:
```
EventContext + NPCState → InterpretationResult(bias, threat_level, salience)
```

---

### 🟢 СРЕДНИЙ — `StateApplicator` принимает только `DecisionResult`

| Проблема | Доказательство |
|---|---|
| `apply_physical()`, `apply_break()`, `apply_tick_recovery()` — отдельные методы с разными сигнатурами | Строки 112, 145, 304 |
| Нет единого контракта «мутатор → дельта → аппликатор» | Каждый метод мутирует по-своему |

**Решение:** После унификации `StateDeltas` — все методы сводятся к `apply(state, deltas: List[StateDelta])`.
