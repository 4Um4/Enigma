## 1. Что это за трек (Слой 0 канонического порядка)

Автор пишет биографию NPC **человеческим языком** → система декомпозирует
(каузально-исполнимые записи EVENT/RELATIONSHIP/EFFECT/…) → автор утверждает
канон («Принять как канон») → сеялка (CCH-4, ещё не построена) отливает
стартовое состояние ДО первого тика. **LLM — декомпозитор, не авторитет**
(INV-LLM-NOT-SSOT; единственный путь к канону — действие автора).

## 3. Живые контуры (проверено)

**Backend:** `cd backend; uvicorn app.main:app` →
- POST /api/chronicle/{campaign}/{npc}/decompose (LLM через ModelRouter)
- GET/PUT /api/chronicle/{campaign}/{npc}/draft
- POST /api/chronicle/{campaign}/{npc_id}/canonize (Save=Contract: 422-класс)
- Файлы: канон `config/npc/chronicles/`, черновики `saves/<campaign>/chronicle_drafts/`
  (корпус Мастера уже там: silver_wolf, Люся ~30 записей, Торнин ~44).

**Frontend (автономный):** `cd frontend; python -m chronicle_editor.editor_launcher`
— 3 панели: NPC-список / лента draft / Разбор. Клавиши: ↑↓ NPC, клик по ленте = выбор
фрагмента, F1/F2 = decompose текущий/следующий Ord, C = взять вопрос в карточку,
1/2/3/4 = резолюция (существующий NPC / создать / массовка / белое пятно),
F9 = «Принять как канон» (блок при открытом вопросе — русский текст ошибки).

**Frontend (Map Editor):** F7 = MODE_CHRONICLE (полноэкранный, read-only лента),
ESC — возврат в карту. Хоткеи заняты: F2=rename, F5=Lab, F6(что-то своё), F12=Workbench.

**LLM:** Q4_K_M канон (вердикт Мастера); сервер поднимай менеджером проекта
(`scripts/llm_server_manager.start_llama_server`) ВНУТРИ python-процесса —
отдельные `python -c` теряют SPAWN-ребёнка. `initialize_router()` обязателен
до любого request() (без регистрации конфигов пул вечно «недоступен»).

## 4. Вердикты владельца (НЕ пересматривать без Мастера)

- Вытеснение фактов: тихо, канон = актуальный снимок; история = git; запущенная
  кампания НЕ обновляется (seed-отлив). Никаких «перечёркиваний».
- Склейка событий: место+время+роли, зеркальная анонимность совместима,
  финал — ВСЕГДА карточка автору.
- Побои-фон (AffectiveImprint-паттерн) vs кружка-событие (триггер) — фон/пик.
- «Уверена, откуда не помню» — легальная запись (confidence без provenance).
- Мембрана vague-relation (normalizer): закрытый реестр маркеров, расширение —
  только через корпус CCH-6.
- События-деградации нормализатора: confidence None → 0.5+needs_confirmation;
  мусорные опции вопросов — поимённо с logger.warning (L4!); confidence вне
  [0,1] — fail-loud. Разница «забыл поле» vs «нарушил схему» несущa.

## 6. Грабли, на которые я наступил (не повторяй)

1. **F-клавиша = греп занятости ДО выбора** (F6 занята — оплачено дважды).
2. **Вставка в elif-цепочку = прочитай окружение целиком** (сломал event_handler,
  IndentationError каскадом; F12-строка съела отступ).
3. **Двойной sys.path-корень фронта**: map_editor/ и frontend/ — разные корни;
   файл в подпакете одного корня, тянущий модуль другого → поднимай пути от
   `__file__` явно (прецедент chronicle/editor_screen.py).
4. **hasattr-антипаттерн**: не угадывай internals core — self-sufficient API
   (ChronicleApi строит HttpClient сама).
5. **git mv + pathspec-коммит**: НОВЫЙ путь обязан быть в pathspec (fixup
   37d30584; старый удалился, новый остался untracked).
6. **IPT-хвост без строки «ИТОГО» = INVALID-прогон** (§3.12) — перезапуск.
7. **Реструктура функции = замена ЦЕЛИКОМ одним БЫЛО/СТАЛО** (двухфрагментная
   вставка дала SyntaxError в аргументах вызова — С333-урок).
8. **Якорь БЫЛО = строка фактического файла** (три версии гейта в памяти —
   разъезд; урок S326/S329 повторён на моём контуре в S336).

## 7. Механика работы (как договаривались)

Один шаг = одна правка → БЫЛО/СТАЛО по фактическому файлу → гейты →
подтверждение Мастера → следующая. Anti-Race: S-номер = max(живой MUTATIONS)+1
при записи; ADR = max атласа+1. pathspec-коммиты, amend запрещён. Выводы
долгих LLM-прогонов — с Итог-строкой (§3.12) в reports/.
