# ENIGMA — BREAK SYSTEM (МЕХАНИКА СЛОМА ВОЛИ)

---

# 0. ЦЕЛЬ СИСТЕМЫ

Создать не “подчинение NPC”, а:

```text
иллюзию контроля при реальной нестабильности поведения
```

Игрок должен чувствовать:

```text
“я его контролирую”
```

в то время как система гарантирует:

```text
контроль всегда частичный и временный
```

---

# 1. БАЗОВЫЙ ПРИНЦИП

```text
Слом — это не переключение состояния.

Это накопление давления,
которое разрушает согласованность личности.
```

---

# 2. СТРУКТУРА ЛИЧНОСТИ

NPC описывается тремя слоями:

---

## L0 — CORE (ядро, почти неизменяемое)

```python
personality_base:
    aggression
    empathy
    dominance
    jealousy
    risk_tolerance
```

---

## L1 — IDENTITY (убеждения, ломаемые)

```python
identity_traits:
    loyalty
    self_respect
    moral_boundaries
    trust_patterns
```

---

## L2 — STATE (текущее состояние)

```python
state:
    fear
    stress
    dependency
    resentment
    willpower
    identity_integrity
```

---

---

# 3. КЛЮЧЕВЫЕ ПАРАМЕТРЫ

---

## 3.1 Willpower

```python
willpower ∈ [0..100]
```

Определяет способность сопротивляться давлению.

---

## 3.2 Pressure

```python
pressure =
    fear
  + stress
  + repeated_failures
  - support
```

---

## 3.3 Identity Integrity

```python
identity_integrity ∈ [0..100]
```

Показывает, насколько личность “цельная”.

---

## 3.4 Resentment

```python
resentment ∈ [0..100]
```

Накопленная скрытая агрессия.

---

## 3.5 Dependency

```python
dependency ∈ [0..100]
```

Привязка к источнику давления (игроку).

---

---

# 4. УСЛОВИЕ СЛОМА

```python
if pressure > willpower:
    trigger_break_progress()
```

---

Важно:

```text
это не момент,
это процесс
```

---

---

# 5. СТАДИИ СЛОМА

---

## 5.1 Сопротивление

```text
willpower высокий
identity стабильна
```

Поведение:

* прямой отказ
* агрессия
* попытки уйти

---

---

## 5.2 Трещины

```text
fear ↑
stress ↑
identity ↓
```

Поведение:

* сомнения
* колебания
* нестабильные реакции

---

---

## 5.3 Рационализация

```text
identity начинает адаптироваться
```

Формируются traits:

```text
self_justification
submission_logic
```

Поведение:

* оправдание давления
* частичное подчинение

---

---

## 5.4 Адаптация (частичный слом)

```text
dependency ↑
willpower ↓
```

Поведение:

* выполнение приказов
* но с внутренним конфликтом

---

---

## 5.5 Деформация личности

```text
identity_integrity ↓↓↓
```

Поведение:

* хаотичность
* эмоциональные скачки
* непредсказуемость
