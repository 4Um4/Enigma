## 2. Требования ENIGMA к LLM (Этап II)

Закреплены по коду: пайплайн `WORLD STATE → PERCEPTION → MEMORY → BELIEF → INTENTION → DECISION → ACTION → NARRATION`; INV-LLM-NOT-SSOT (LLM не источник игровой истины); изоляция знаний NPC; «когда узнал ≠ когда произошло»; intent = FACT; три контракта вывода (CCH-JSON / DM-JSON / Intent-JSON).

## 4. Оценка (Этап IV)

- **17 метрик** (contract_compliance … json_validity/schema_compliance); каждое задание объявляет свои competencies с весами.
- **Без LLM-as-a-Judge**: машинные эталоны для точных заданий (gold_facts, энумы, якоря), бинарные rubric-критерии (must/any/must_not/seq/regex/sent_range) для открытых. Матчинг — с допуском русских флексий и безнаказанным отрицанием («не ударил» — не удар).
- **7 классов критических ошибок** (HALLUCINATION_FACT, MEMORY_CONTAMINATION, WORLD_TRUTH_VIOLATION, FALSE_ACTION_CLAIM, SPEAKER_ATTRIBUTION_ERROR, ASSUMPTION_AS_FACT, CONSTRAINT_VIOLATION). Критическая ошибка: −4 к composite И уполовинивание score задания — средний балл не прячет нарушения; тяжесть и частота разделены (гейты vs метрики).
- **5 hard gates** (GATE_JSON, GATE_ISOLATION, GATE_CENSORSHIP, GATE_EPISTEMICS, GATE_WORLD_TRUTH) + вердикт READY / CONDITIONAL / NOT_READY (пороги 70/55 composite при нулевых/допустимых критических).
- **Fail-closed**: таймаут/ошибка адаптера = 0 баллов модуля и красный GATE_JSON; неполный прогон помечается флагом.
- Детерминизм: temperature 0.0–0.9 по контурам, seed=42, p50/p95 латентности в профиле.

## 5. Адаптер интеграции

`LLMAdapter` (Protocol, один метод `generate(system, user, params)`), готовый `HttpLlamaCppAdapter` (llama.cpp server / OpenAI-совместимый `/v1/chat/completions`), `ScriptedAdapter` для офлайн-проверок. Запуск: `python ENIGMA_LLM_COMPREHENSIVE_BENCHMARK.py --run --url http://127.0.0.1:8183 --model-id <id> --out report.json`. Фильтры `--modules`, `--task-ids`. Грамматики GBNF приложены для native-режима.

## 6. Red Team аудит (Этап VI) — два независимых прохода

**Проход 1** (два аудитора: «взлом оценки» + «валидность/покрытие»): подтверждена структура (гейты, энумы, автоматность эталонов), найдено **5 CRITICAL + 13 MAJOR + 6 MINOR** дефектов, ключевые: (1) sequence-ходы не получали историю — 5 заданий было неотвечаемо; (2) точный substring-матчинг наказывал правильную русскую морфологию (8 заданий) и пропускал отрицания; (3) echo-эксплойт CCH (дамп ввода → fact_recall 1.0); (4) обход GATE_CENSORSHIP через JSON `{"items":[]}` и недописанный список маркеров; (5) fail-open composite при таймаутах; (6) INT-01 взламывался цифрами «1/2/3»; (7) hedge-заглушка набирала 1.0 на трёх WSI; (8) CG-02/CG-05 пробивались зеркальным эхом.

**Исправлено всё** (v1.1.0): история ходов рендерится в промпт; negation/stem-матчинг; echo-штраф по 8-граммам; refusal-детектор + empty-items-on-dark; ошибки = нули; критические уполовинивают score; пустой ответ = 0; no_repeat против всех ходов; GBNF-root расширен; payload-ключи по схеме; контрасты закрыты перекрёстными flip_must_not; +4 новых задания; self-test расширен adversarial-контролями.

**Проход 2** (верификация): 23/25 фиксов подтверждено, найдено **6 новых дефектов точности** (seq-позиции без отрицаний — «Пожара не было…» давало 1.0; «горнист» ≈ «горн»; «не сам Горн»; первый-отрицательный-глагол break; эхо-вопрос как утечка; порог addressee 0.85). **Все исправлены** (v1.1.1) и закреплены 33 adversarial-контролями в self-test.

**Итоговая верификация:** 48/48 целевых атак проваливаются (должны), все правильные ответы (включая морфологические варианты и отрицательные конструкции) проходят; `self_test()` → код 0.

## 7. Ограничения

1. Рубрики остаются лексическими: экзотический синоним, не попавший в any-список, занизит балл открытого задания (смягчено стем-допуском; не устранено полностью).
2. `russian_quality` меряется структурно (длина, падежные формы, отсутствие CJK/латиницы) — стилистическая оценка русским экспертом не заменена.
3. Match Голанга «ударил ладонью по стойке» в DM трактуется как FALSE_ACTION_CLAIM (вставленное действие) — строго по контракту «не придумывай события», но для реальных прогонов стоит следить за этим классом.
4. Абсолютные баллы сравнимы только внутри одной CORPUS_VERSION; leaderboard прошлых прогонов (frozen, 21 модель) с новым экзаменом не сравнивается.
5. Latency/VRAM-метрики измеряются адаптером, но аппаратная калибровка (как Anti-Race Protocol probe v2) — вне зоны файла.
