## Отличная идея — "странник" как интерфейс внешнего мира

Это решает сразу 3 проблемы архитектурно чисто:

### Что такое странник в терминах системы

**Не NPC** — это *событие*. У него нет:
- Психологии (drives, psycho)
- Потребностей (FOOD, SOCIAL)
- Стресса
- Интентов для DecisionHub

У него есть:
- Инвентарь (что привёз)
- Золото (ограниченное)
- Цель (купить X, продать Y)
- Временное присутствие (пришёл → торговля → ушёл)

Это **экономический пинг** — как пинг в сети проверяет что сервер жив, странник проверяет что экономика дышит.

---

### Частота появления — случайность, не расписание

В реальности караваны не приходят по таймеру. Факторы:
- Погода (зимой реже)
- Спрос (если слух о дешёвом товаре — придут быстрее)
- Случайность (грабители на дороге, болезнь)

```
P(приход) = base_chance × seasonal_modifier × demand_modifier
base_chance = 0.3 (30% каждый день = ~2 раза в неделю)
```

При 75 днях это ~22 визита — достаточно для merchant, но не гарантия.

### Что покупает/продаёт

|-------|--------|--------|
| cloth | merchant_goran | Основной товар локации |
| tools | blacksmith_orm | Ремесленная продукция |

**Привозит (чего нет):**
| Товар | Зачем | Для кого |
|-------|-------|----------|
| lockpick | Для вора | thief_shadow |
| silk | Роскошь | merchant (перепродажа?) |
| iron | Сырьё | blacksmith (если закончился) |

### Для thief — окно возможности

Странник создаёт **target of opportunity**:
- Пришёл → у него есть золото и товары
- Thief видит (perception check)
- Решает: красть или нет (risk_tolerance из psycho)

Если украл:
- Получает flow (доход) → INCOME satisfaction
- Риск: если неуспех → стресс, возможный конфликт

### Архитектурный вопрос

Где жить — в sandbox или в economy?

**Мой proposal:**
```
backend/app/services/economy/traveller.py
```

Лёгкий класс без зависимости от NPCState. В sandbox вызываете напрямую. В game_loop — через WorldTickEngine.

```python
@dataclass
class TravellerVisit:
    """Один визит странника — не сущность, а событие."""
    tick: int
    gold_budget: float
    wants_to_buy: Dict[str, float]   # {"cloth": 5, "tools": 2}
    brings_to_sell: Dict[str, float] # {"lockpick": 2, "silk": 1}
```
