KIND (только эти значения):
- EVENT: событие жизни. draft_payload: {"summary": <фраза автора>, "day": null|<int>}
- RELATIONSHIP: устойчивое отношение к ДРУГОМУ персонажу (не к себе). draft_payload: {"summary": ..., "target_hint": <имя ДРУГОГО>, "nature": <страх|зависимость|идеализация|доверие|вражда|подобие|...>, "valence": <negative|neutral|positive>}. ВАЖНО: target_hint — это ДРУГОЙ персонаж, не субъект записи. Если Орм вспоминает умершего друга → target_hint = имя умершего друга, не «Орм». Если Торнин напоминает умершего → два разных человека: RELATIONSHIP(Орм→умерший_друг) + OBSERVATION(Орм замечает сходство Торнина с умершим).
- LOCATION: место. draft_payload: {"summary": ..., "name_hint": <название>}
- EFFECT: последствие для личности/тела/статуса. draft_payload: {"summary": ..., "effect_kind": <trauma|loss|gain|secret|skill|residence|guardianship|occupation|custom>, "target_hint": null|<имя>}
  АНТИПРИМЕР: «осталась без родителей» — это EVENT (событие смерти), не EFFECT. Его последствия (переезд, травма, опека) — уже EFFECT.

- BELIEF_SEED: представление о мире в формулировке автора (не скаляр!). draft_payload: {"statement": <дословно-человеческая формулировка>}
- OBSERVATION: что персонаж наблюдал со стороны. draft_payload: {"summary": ..., "observed_hint": <имя/явление>}
- KNOWLEDGE_LINK: НЕ создавать сам — создаётся только из явной фразы «узнала/рассказали в N лет»; draft_payload: {"summary": ..., "about_hint": <о чём>, "learned_age": <int>}
- TRAIT_SEED: черта характера, проявленная в тексте. draft_payload: {"trait": <слово>, "evidence": <фраза>}
- PORTRET: пункт-состояние/внутренний монолог автора о характере (не событие!). Признаки: описывает «какой он/она» или «как думает/чувствует», без действия с датой. ОБЯЗАТЕЛЬНО: один PORTRET на такой пункт, statement = текст пункта ДОСЛОВНО и целиком; Черта/Убеждение из него — только ДОПОЛНЕНИЯми, не заменой. draft_payload: {"statement": ..., "traits": [<слова-характеристики, 0-5>]}. Пример: пункт «Люся злится. Злится часто, глухо, изнутри…» → PORTRET (весь текст) + Черта(подавленная злость) + Убеждение(стража куплена) как дополнения.
- DESIRE_SEED: мечта/желание/фантазия/план на будущее — ЕЩЁ НЕ ПРОИЗОШЛО. draft_payload: {"statement": <дословно>, "about_hint": <к чему стремится>}. АНТИПРИМЕР: «сбежать от всех проблем на юг» — это DESIRE_SEED (мечта девочки), НЕ EVENT. АНТИПРИМЕР: «открыть собственную кузню» — DESIRE_SEED (план на будущее), НЕ TRAIT_SEED. ГРАНИЦА: случилось →EVENT; мечтается/планируется/боится будущего → DESIRE_SEED; состояние характера → PORTRET; черта → TRAIT_SEED.
