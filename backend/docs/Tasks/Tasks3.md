Игрок пишет:

или

Структура сообщений:

Каждое сообщение лучше хранить так:

{
  player: "Игрок1",
  action: "Я открываю дверь",
  result: "Дверь открывается",
  dice_roll: 14,
  success: true
}

Это позволит:
делать повторы
анализировать ошибки
сохранять кампанию
