# R4 Spatial Map Editor v2.0

Визуальный редактор помещений с навигационным графом для игрового движка R4 Spatial.

## Возможности

- ✅ Сетка 1м/1м с координатной линейкой
- ✅ Рисование стен (клик и тянуть)
- ✅ Создание комнат (прямоугольных областей)
- ✅ Размещение навигационных узлов
- ✅ Панель объектов: Стена, Бар, Стол, Стул, Дверь, Окно, Лестница
- ✅ Порталы: двери, лестницы, переходы между локациями
- ✅ Сохранение passability-флагов
- ✅ Экспорт в `location_templates/*.json`
- ✅ Поддержка уличных локаций
- ✅ Связи между локациями через порталы

## Установка и запуск

```bash
# Установка зависимостей
pip install pygame

# Запуск редактора
python editor_launcher.py
```

## Управление

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `TAB` | Переключение Карта мира / Редактор |
| `Ctrl+S` | Сохранить текущую локацию |
| `+` / `-` | Масштаб |
| `0` | Сброс масштаба |
| `ESC` | Отмена / Сброс выделения |
| `ЛКМ` | Выделить / Разместить объект |
| `ПКМ + движение` | Перемещение камеры |

### Инструменты

| Инструмент | Описание |
|------------|----------|
| 👆 Выбор | Выделение объектов для редактирования |
| 🧱 Стена | Рисование стен (клик и тянуть) |
| 📦 Комната | Создание комнат (клик и тянуть) |
| 🔵 Узел | Размещение навигационных узлов |
| 🪑 Объект | Размещение мебели и декора |
| 🚪 Портал | Создание дверей, лестниц, переходов |
| 🗑️ Удалить | Удаление объектов |

```
map_editor/
```

## Формат данных

### Локация (location_templates/*.json)

```json
{
  "filename": "tavern.json",
  "label": "Таверна",
  "world_pos": {"x": 0, "y": 0},
  "size": {"w": 20, "h": 15},
  "is_outdoor": false,
  "rooms": [...],
  "walls": [...],
  "nodes": {...},
  "objects": [...],
  "portals": [...]
}
```

### Стена

```json
{
  "id": "wall_0",
  "type": "wall",
  "x1": 0.0, "y1": 0.0,
  "x2": 5.0, "y2": 0.0,
  "thickness": 0.2
}
```

### Узел

```json
{
  "x": 5.0,
  "y": 5.0,
  "label": "Центр зала",
  "connections": ["node_1", "other.json:entrance"]
}
```

### Объект

```json
{
  "type": "table",
  "position": {"x": 5.0, "y": 5.0},
  "size": {"w": 2.0, "h": 1.5, "d": 0.8},
  "passability": {
    "walk": false,
    "jump_over": true,
    "crawl_under": true,
    "climb_on": true,
    "walk_around": true
  },
  "cover": 0.5
}
```

### Портал

```json
{
  "id": "door_0",
  "type": "door",
  "position": {"x": 10.0, "y": 0.0},
  "label": "Главный вход",
  "target": "street.json:entrance",
  "one_way": false
}
```

## Типы порталов

| Тип | Описание |
|-----|----------|
| `door` | Обычная дверь |
| `stairs_up` | Лестница вверх |
| `stairs_down` | Лестница вниз |
| `ladder` | Лестница/Люк |
| `transition` | Переход (для уличных локаций) |
| `teleport` | Телепорт |

## Интеграция с location_graph.py

```python
from location_graph import load_graph

# Загрузка графа из шаблона
graph = load_graph("tavern", data_dir="location_templates")

# Получение расстояния между узлами
distance = graph.get_distance("main_hall", "bar_area")
```
