```python
class DialogueSession:
    def __init__(self, npc_id, player_id):
        self.buffer = []  # последние 5 реплик
        self.topic = None  # текущая тема ("подвал", "еда", "вор")
        self.emotional_markers = []  # ["defensive", "evasive"] — для LLM prompt
        
    def add(self, speaker, text, emotional_tone=None):
        self.buffer.append({"speaker": speaker, "text": text, "tone": emotional_tone})
        if len(self.buffer) > 5:
            self.buffer.pop(0)
```

```python
              if (i.actor == actor and i.target == target)
              or (i.actor == target and i.target == actor)
              and current_tick - i.tick < lookback]

    # Взвешенная сумма по свежести
    trust = sum(i.valence * (1 - (current_tick - i.tick)/lookback) 
                for i in recent if i.action in ["trade", "help", "promise"])
    fear = sum(-i.valence * ... 
               for i in recent if i.action in ["threaten", "attack", "dominate"])
    
    return normalize(trust, fear, ...)
```

#### 1.3 Влияние на DecisionHub

```python
# Вор выбирает intent
candidates = ["trade", "steal", "avoid", "threaten"]

for intent in candidates:
    if intent == "trade" and relations["player"]["trust"] < -0.5:
        score -= 0.5  # не торгует с тем, кого не доверяет
    if intent == "avoid" and relations["player"]["fear"] > 0.7:
        score += 0.3  # избегает того, кого боится
        
# Выбираем максимум
```

#### 1.4 Что в файле

`relations` в `lucy_memory.yaml` больше не ручные. Они **пересчитываются** из `interactions.yaml` при каждом дампе. Ты видишь результат, но не редактируешь вручную (можешь, но при следующем дампе перезатрётся).

```python
# При загрузке в LLM
def recall(npc_id, trigger_tags=None):
    events = load_events(npc_id)
    
    # Базовый отбор: accessibility > 0.2
    available = [e for e in events if e.accessibility > 0.2]
    
    # Если есть триггер (игрок сказал "подвал")
    if trigger_tags:
        triggered = [e for e in events 
                     if any(t in e.tags for t in trigger_tags)]
        # Для триггеров accessibility не важна — важность решает
        available.extend([e for e in triggered if e.importance > 0.5])
    
    # Сортируем по релевантности
    scored = [(e, e.importance * e.accessibility * recency_bonus(e)) 
              for e in set(available)]
    return sorted(scored, key=lambda x: x[1], reverse=True)[:4]
```

#### 2.2 Секреты

Если `is_secret: true` и игрок в `hidden_from` — факт не попадает в LLM-пrompt. Но если Люся под давлением (stress > 0.8) или игрок использует `persuasion` с высоким навыком — проверка на `discovery`:

```python
def discovery_check(event, npc, pressure):
    # Чем выше pressure, тем ниже порог
    threshold = 0.7 - pressure * 0.3
    if event.accessibility > threshold:
        return True  # всплыло
    return False
```

#### 3.2 Как сжимать

**Вариант A (сейчас):** Шаблоны. Если 3+ события с одинаковыми тегами (`player`, `friendly`) и `importance < 0.5` — объединить.

**Вариант B (потом):** LLM. Передаёшь 3 события, просишь: "Сожми в одно предложение". Получаешь `summary`. Но это тратит токены.

Рекомендую **Вариант A сейчас**, **Вариант B как опцию** при >50 событиях.

#### 3.3 Что в файле
