# PDF Drop Folder

Сюда можно положить файлы `.pdf`, `.txt`, `.md` для быстрой загрузки в память мастера.

Примеры:
- `правила_книга_игрока.pdf`
- `campaign_icewind_dale.pdf`
- `npc_bestiary.pdf`

Запуск импорта в терминальном режиме:
1. Запустите `python run_terminal_dm.py` из папки `backend`.
2. Введите команду `/ingest`.

Файлы автоматически раскладываются по типу знаний по имени файла (rules/campaign/npc/characters/world).
